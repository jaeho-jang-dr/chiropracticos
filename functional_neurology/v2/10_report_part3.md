# [Evidence-Based] <abbr class="med-abbr" title="Functional Neurology · 기능 신경학">FN</abbr> Report 3/4 — ⭐ Assessment 심화 (Part IV)

### 1. 서론: 기능 신경학적 평가의 임상적 당위성

기능 신경학(Functional Neurology, FN) 임상 현장에서 **'측정할 수 없는 것은 치료할 수 없다(You cannot treat what you cannot measure)'**는 원칙은 평가의 당위성을 관통하는 핵심 철학입니다. 기능 신경학적 평가는 단순한 질병의 유무를 판단하는 진단학적 범주를 넘어, 신경계의 기능적 건전성을 정량화하는 과정입니다.

*   **하드웨어(구조)와 소프트웨어(기능):** 전통적인 의학적 접근이 <abbr class="med-abbr" title="Magnetic Resonance Imaging · 자기공명영상">MRI</abbr>나 CT를 통해 종양이나 골절 같은 '하드웨어'의 파손을 찾는다면, FN은 신경 회로의 효율성과 정보 처리 능력인 '소프트웨어(Grey area)'의 기능 이상을 평가합니다. 뇌 영상이 정상임에도 환자가 느끼는 어지럼증, 인지 저하, 만성 통증은 대개 이 '소프트웨어'적 불균형에서 기인합니다.
*   **치료 타겟 결정 및 CIS 분석:** 평가는 뇌 균형(Hemisphericity)의 불균형 지점을 파악하고, 개별 신경 세포의 중추 통합 상태(Central Integrative State, CIS)를 분석하여 자극의 역치와 재활 강도를 결정하는 근거가 됩니다.
*   **기준선(Baseline) 설정:** 치료 전 객관적인 기준선을 설정함으로써 신경 가소성(Neuroplasticity)에 의한 긍정적 변화를 추적하고 환자와 데이터 기반으로 소통합니다.
*   **Red Flag 배제:** 기능적 재활 이전에 생명을 위협하거나 즉각적인 수술이 필요한 기질적 병변(Ablative Lesions)을 선별하여 임상적 안전성을 확보합니다.

### 2. 4.1 평가의 5단계 계층 구조 (The 5-Level Assessment Hierarchy)

신경계의 복잡한 네트워크를 논리적으로 분석하기 위해 다음과 같은 5단계 계층 구조를 적용하여 평가를 수행합니다.

1.  **1단계: 병력 청취(History)** - 주소증 파악 및 신경학적 배경 탐색 (OPQRST + FN)
2.  **2단계: 관찰(Observation)** - 정적/동적 자세, 보행, 피부 상태를 통한 비언어적 징후 포착
3.  **3단계: 기본 신경학 검사(Basic Neurology)** - 뇌신경, DTR, 병적 반사, 근력(<abbr class="med-abbr" title="Manual Muscle Testing · 도수 근력 검사">MMT</abbr>) 확인
4.  **4단계: FN 특화 검사(Functional Neurology Specifics)** - 안구 운동, 전정 기관, 소뇌, 자율신경계 및 뇌 균형 정밀 분석
5.  **5단계: 영상 및 실험실 의뢰(Imaging/Lab Referral)** - 기질적 병변 확진을 위한 MRI, CT, 혈액 검사 의뢰

---

### 3. 4.2 History — OPQRST + FN 특화 항목

환자의 주관적 보고를 객관적 신경학적 지도로 변환하기 위해 표준 OPQRST와 FN 전용 질문지를 합성하여 사용합니다.

| 질문 항목 | 세부 내용 (OPQRST) | 임상적 의도 및 FN 특화 질문 |
| :--- | :--- | :--- |
| **Onset** | 발병 시기 및 상황 | 기질적(갑작스러운 외상) vs 기능적(점진적 불균형) 감별 |
| **Provocation** | 악화/완화 요인 | 특정 머리 움직임, 빛/소리 과민성, 자세에 따른 증상 변화 |
| **Quality** | 증상의 성격 | 둔한 통증, 박동성, 회전성 어지럼증, 인지적 안개(Brain Fog) |
| **Region** | 발생 부위 | 피부분절(Dermatome) 및 말초신경 포착 지점(<abbr class="med-abbr" title="Thoracic Outlet Syndrome · 흉곽출구 증후군">TOS</abbr>, 수근관 등) 확인 |
| **Severity** | 강도 (<abbr class="med-abbr" title="Visual Analog Scale · 시각 아날로그 척도">VAS</abbr> 0-10) | 자율신경계 과활성(교감신경 항진)과의 상관관계 파악 |
| **Timing** | 시간적 패턴 | 지속성 vs 간헐성, 하루 중 증상이 심해지는 시간대 분석 |
| **FN 특화** | **<abbr class="med-abbr" title="Traumatic Brain Injury · 외상성 뇌손상">TBI</abbr>/Concussion** | 과거 두부 외상력, 의식 소실 여부, 외상 후 인지/감각 변화 |
| **FN 특화** | **자율신경 징후** | 기립성 어지럼증, 소화 불량, 심계항진(Tachycardia), 수면 장애 |

---

### 4. 4.3 Red Flag 스크리닝: 즉각적 의뢰 리스트

기능적 접근 이전에 반드시 배제해야 할 중증 병변(Ablative Lesions) 징후입니다. 아래 항목 중 하나라도 해당할 경우 재활을 중단하고 즉시 상급 의료기관으로 의뢰하십시오.

> 🚨 **즉시 응급실/신경과 의뢰 필요 (Red Flags)**
> *   **생애 최악의 두통:** 갑작스럽고 극심한 번개형 두통 (뇌출혈/혈관 병변 의심)
> *   **마미 증후군(Cauda Equina):** 갑작스러운 대소변 장애, Saddle Anesthesia(회음부 감각 저하)
> *   **진행성 근력 약화:** 근력이 시간 단위로 빠르게 소실되는 양상
> *   **외상 후 급성 신경학적 결손:** 사고 직후 나타나는 편측 마비, 언어 장애, 극심한 현훈
> *   **경부 경직(Nuchal Rigidity):** 발열을 동반한 목의 강직 (수막염 의심)

### 5. 4.4 관찰 평가 (Observation)

진료실 문을 열고 들어오는 순간부터 신경계의 기능적 출력을 관찰합니다.

*   **3면 자세 분석:** 정/측/후면에서의 불균형을 분석합니다. 특히 대뇌 두정엽(Parietal Lobe) 기능 저하 시 관절 위치 감각(Joint Position Sense) 오류로 인한 머리 위치의 변화가 관찰됩니다.
*   **보행 패턴(Gait):** 팔 흔들기(Arm swing)의 비대칭성은 대뇌 피질 및 기저핵 불균형을 반영합니다. (예: 오른쪽 팔 흔들기 감소는 왼쪽 대뇌 또는 오른쪽 소뇌 기능 저하 시사)
*   **피부 상태 및 안면 대칭:** 자율신경계 불균형을 반영하는 피부 변색, 비정상적 발한, 동공 크기 차이(Anisocoria), 눈꺼풀 처짐(Ptosis)을 체크합니다.

### 6. 4.5 기본 신경학 검사 (Basic Neurological Exam)

기본 검사는 신경계의 하드웨어적 건전성을 확인하며, FN에서는 이를 뇌 균형 분석의 기초 자료로 활용합니다.

| 검사법 | 양성 소견 | 임상적 의미 (FN 관점) |
| :--- | :--- | :--- |
| **뇌신경(I-XII)** | 비대칭적 반응 | 뇌간(Brainstem) 및 중뇌/교뇌/연수 기능 저하 스크리닝 |
| **DTR (심부건 반사)** | 0(소실) ~ 4+(항진) | UMN(피질척수로) 손상 시 항진, LMN 손상 시 저하 |
| **병적 반사** | Babinski, Hoffman (+) | 상위운동뉴런(UMN)의 억제 제어 상실 |
| **MMT (근력 검사)** | 0 ~ 5 등급 | **주의:** 소뇌 기능 저하 시 척추 심부 근육(Intrinsic Muscle) 약화와 척추 불안정성이 동반됨 |
| **고위 감각 평가** | Stereognosis 저하 | 두정엽(Parietal Lobe)의 감각 통합 기능 및 입체 인지 능력 분석 |

---

### 7. 4.6 소뇌 및 고유수용성 감각 평가

소뇌는 운동의 정확성뿐만 아니라 척추 안정성 유지의 핵심입니다. 소뇌 기능 저하는 단순한 분절 교정(Segmental Adjusting)으로 해결되지 않는 척추 불안정성을 야기합니다.

1.  **Finger-to-nose / Heel-to-shin:** 겨냥이상(Dysmetria)이나 의도성 떨림 확인. 불균형이 나타나는 측면은 동측 소뇌 기능 저하를 시사합니다.
2.  **RAM (Rapid Alternating Movements):** 교대운동불능(Dysdiadochokinesia) 평가. 리듬의 분절화는 소뇌 외측부의 기능 저하를 의미합니다.
3.  **Romberg / Tandem Gait:** 눈을 감았을 때 균형 상실이 심해진다면 전정 기관 및 고유수용성 감각 통합의 오류를 의미하며, 이는 대뇌와 소뇌 간의 피드백 루프 결함과 관련이 있습니다.

---

### 8. 4.7 전정 기관 검사 (Vestibular Assessment)

전정-안구 반사(<abbr class="med-abbr" title="Vestibulo-Ocular Reflex · 전정안반사 — 머리 회전 시 망막상 안정화 반사">VOR</abbr>)와 전정-척수 경로의 통합 상태를 평가합니다.

| 검사명 | 수행 방법 및 임상적 유의성 | 양성 기준 및 의미 |
| :--- | :--- | :--- |
| **Dix-Hallpike** | 머리를 45도 회전 후 빠르게 눕혀 안진 유도 | 양성 시 <abbr class="med-abbr" title="Benign Paroxysmal Positional Vertigo · 양성돌발성체위현훈 (이석 이탈)">BPPV</abbr>(이석증) 시사 |
| **Head Impulse (<abbr class="med-abbr" title="Head Impulse Test · 두부충동검사 (Halmagyi)">HIT</abbr>)** | 시선을 고정시킨 채 머리를 빠르게 회전 | 시선 고정 실패(Saccade 발생) 시 VOR 기능 저하 |
| **Fukuda Stepping** | 눈을 감고 제자리에서 50~100보 보행 | 45도 이상 회전 시 해당 방향의 전정 기능 저하 가능성 |
| **<abbr class="med-abbr" title="Dynamic Visual Acuity · 동적시력 (VOR 기능 정량)">DVA</abbr> (Dynamic Visual Acuity)** | 머리를 흔들며 시력판을 읽는 능력 평가 | 전정 기관의 시각적 안정화 능력(VOR) 분석 |

---

### 9. 4.8 안구 운동 평가 (Oculomotor)

안구 운동은 대뇌 피질, 뇌간, 소뇌의 통합적 CIS를 반영하는 '신경계의 창'입니다.

*   **VOR (전정-안구 반사):** 머리 움직임 시 시각적 타겟을 고정하는 능력.
*   **Saccade (단조성 운동):** 새로운 타겟으로 눈을 빠르게 이동시키는 능력. 과소/과대 측정(Dysmertia)은 소뇌 및 전두엽 안구 운동 영역의 불균형을 반영합니다.
*   **Smooth Pursuit (추적 운동):** 움직이는 타겟을 부드럽게 따라가는 능력. 끊어짐 현상(Saccadic intrusion)은 두정엽 및 소뇌 기능 저하와 관련됩니다.
*   **NPC (눈 모음 근접점):** 정상 범위는 코끝에서 **5-6cm** 이내입니다. 뇌진탕(Concussion) 환자에게서 빈번하게 확장됩니다.
*   **<abbr class="med-abbr" title="Vestibular/Ocular Motor Screening · 전정-안구운동 선별검사 (Mucha 2014)">VOMS</abbr> (Mucha 2014) 프로토콜:**
    *   **단계:** Smooth Pursuit → Saccades → Convergence → VOR (Horizontal/Vertical) → Visual Motion Sensitivity (VMS).
    *   **평가:** 각 항목 수행 후 두통, 어지럼증, 메스꺼움, 흐릿함 증상을 **0-10 척도**로 기록하여 증상 유발 여부를 정밀 분석합니다.

---

### 10. 4.9 자율신경계 및 CIS 평가

중추 통합 상태(CIS)의 불균형은 자율신경계의 비정상적 출력을 통해 나타납니다. 뇌 균형(Hemisphericity)의 차이는 좌우 교감/부교감 신경의 비대칭적 활성을 유도합니다.

| 지표 | 정상 범위/반응 | 불균형 징후 (Hemisphericity/CIS 저하) |
| :--- | :--- | :--- |
| **기립성 활력징후** | 체위 변화 시 안정적 유지 | **기립성 빈맥(Tachycardia)**, 혈압 불안정, 현훈 |
| **심박 변이도 (HRV)** | 높은 변이도 (유연한 적응) | 변이도 감소 (만성 스트레스 및 신경계 피로 상태) |
| **동공 빛 반사 (PLR)** | 빠르고 지속적인 수축 유지 | 느린 수축, 수축 유지 실패(Fatigue), Hippus 현상 |
| **심혈관 반응** | 규칙적인 리듬 | **심장 부정맥(Cardiac Arrhythmia)**, 혈압 상승 |

---

### 11. 4.10 평가 결과 기록 및 신뢰도

평가는 치료의 방향을 결정하는 유일한 근거이므로 재현성 있는 기록이 필수적입니다.

*   **SOAP 및 정량화:** "균형이 나쁨" 대신 "Romberg 시 오른쪽으로 15도 기울어짐", "NPC 12cm"와 같이 수치화된 데이터를 기록합니다.
*   **말초 신경 포착(Entrapment) 스크리닝:** FN 임상가는 뇌 균형에 따른 근육 불균형이 말초 신경을 압박하는 지점을 확인해야 합니다.
    *   **체크리스트:** TOS(흉곽출구), Pronator Teres, Piriformis, Peroneal Nerve, Carpal Tunnel Syndrome 등.
*   **신뢰도(Reliability) 확보:** Hickey(2021) 등에 따르면 표준화된 프로토콜 준수는 검사자 내/간 신뢰도를 높여 재활의 유효성을 입증하는 근거가 됩니다.

3. **뇌 균형(Hemisphericity) 불균형 시 나타날 수 있는 자율신경 징후는?** (답: 고혈압, 빈맥(Tachycardia), 심장 부정맥 등)
4. **VOMS 프로토콜에서 증상을 평가하는 기준은?** (답: 두통, 어지럼증, 메스꺼움, 흐릿함을 0-10 척도로 점수화)
5. **두정엽(Parietal Lobe) 기능 저하 시 나타나는 특징적 감각 결손은?** (답: 관절 위치 감각(Joint Position Sense) 저하 및 입체 인지 능력 감소)
6. **말초 신경 포착 증후군 중 흉곽 부위에서 흔히 발생하는 것은?** (답: TOS(흉곽출구증후군))
7. **CIS(중추 통합 상태)를 결정하는 요소는?** (답: 신경 세포에 도달하는 모든 흥분성 및 억제성 입력의 총합)
8. **신경 가소성(Neuroplasticity)을 형성하는 핵심 동력은?** (답: 감각, 운동, 인지적 경험의 강도(Intensity)와 빈도(Frequency))
