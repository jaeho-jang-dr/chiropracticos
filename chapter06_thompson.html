개요

본 챕터가 다루는 기법

Segmental Drop Table의 공압 낙하 보조 추력 + Derifield-Thompson leg check 분석. 최소 힘·고속 추력으로 고령·임산부·HVLA 거부 환자에 적합.

근거

🟡 Moderate — 요추·골반 SMT

이론·기전

모든 카이로프랙틱 기법은 Afferentation → 중추 처리 → Efferentation 프레임(Chapter 2 참조)에서 해석합니다. 이 기법이 어떤 구심성 입력을 만들고 어떤 원심 출력을 조절하는지.

창시자와 역사적 맥락

J. Clay Thompson(1908-1986)은 1955년경 Terminal Point Technique을 발표하며 분절형 드롭 테이블(drop table)의 임상 적용을 정립했습니다. 테이블의 경추·흉추·요추·골반 섹션이 각각 사전 장력에 의해 들려 있다가 시술자의 추력에 맞춰 짧게 떨어지는(drop) 구조로, 시술자가 환자에게 전달하는 압축력은 줄이면서 분절에 가해지는 운동량은 유지하도록 설계되었습니다. Thompson은 또한 prone leg-length 검사(Derifield 변형)를 시술 결정에 활용했지만, 이 검사의 측정자 간 신뢰도(inter-rater reliability)는 낮다는 보고가 다수이므로 (Cooperstein 2013 review 등) 단독 진단 도구가 아닌 참고 지표로 다뤄야 합니다.

생체역학 — 드롭 테이블의 물리

Drop section은 ~1.5-3 cm 들려 있다가 추력에 동조하여 짧은 시간(수십 ms) 내에 떨어지며, 시술자 손과 환자 분절 사이의 접촉 시간(dwell time)을 단축하고 피크 속도(peak velocity)를 유지합니다. 결과적으로 환자에게 전달되는 총 충격량(impulse)은 비슷하지만 피크 압력은 감소합니다. 큰 체격·골다공증 경향·통증 과민 환자에서 표준 manual HVLA를 안전하게 대체하거나 보완하는 수단으로 쓰입니다.

신경생리 — Afferentation → Central → Efferentation

  • 🟢 Afferentation — 드롭에 의한 가속도가 Type I·II 기계수용기와 근방추를 짧고 빠르게 자극. 자극 양식은 표준 HVLA와 유사하나, 시술자 측 잔류 부하가 줄어 깊은 분절·중량 환자에서도 적용이 용이.
  • 🟡 중추 처리 — Diversified HVLA와 동일한 후각·중뇌·뇌간 경로 (gate control, DNIC, 자율신경 톤 변화)로 추정.
  • 🟢 Efferentation — 척추주위근 EMG 정상화, 통증 유발 근방어 감소, 관절가동범위(ROM) 단기 증가.

🟠 Derifield/leg-length 진단의 한계

Prone leg-length 검사는 측정자 간 일치도가 낮고, 다리 길이 차이의 진단적 의미가 제한적이라는 비판이 있습니다(Cooperstein 2013 review 등). Thompson 시술 결정은 leg check 단독이 아닌 병력·자세·정적/동적 촉진·증상 일치를 모두 고려해 내리는 것을 권합니다.

Derifield-Thompson Leg Check 분석

복와위에서 하지장(apparent leg length)을 비교해 기능장애 분절을 경추 / 골반(PI·EX·IN) / 천골(전방·후방 회전) 수준으로 구분하는 Thompson 고유 분석법. Romer & Mabel Derifield(1940-50년대)의 원형을 Thompson이 체계화했다.

🟠 신뢰도 주의

측정자 간 신뢰도(ICC 0.3-0.7)가 제한적이므로, leg check는 보조 분석 도구로만 활용하고 Motion Palpation·정형학 검사와 반드시 병행해야 한다 (Cooperstein 2013 review).

① 기본 검사 순서 (3단계)

  1. 신전 단계 — 복와위, 무릎 펴고 발뒤꿈치(medial malleolus) 기준으로 하지장 비교 → 짧은 다리(short leg) 측 확인.
  2. 굴곡 단계 — 양 무릎을 90도로 굴곡 후 하지장 비교 → +D/-D 감별.
  3. 경추 테스트 — 머리를 좌·우로 회전시키며 하지장 변화 관찰 → 경추 증후군 여부.

② 경추 증후군 (Cervical Syndrome)

소견

신전 상태에서 머리를 좌·우로 회전할 때, 불균형했던 하지장이 동등해지거나 반대로 동등했던 하지장에 차이가 생기는 반응.

해석 원리

경추 회전이 하지장 균형에 영향을 미쳤다면, 신경 간섭의 근원이 상부 경추(C1-C2)에 존재함을 시사한다. 목의 고유수용성 수용기가 자세 조절 및 하지 근긴장과 신경학적으로 연결되어 있기 때문이다.

임상 적용: 골반 교정에 앞서 상부 경추를 우선 교정 → 재평가.

③ 양성 데리필드 (+D, Positive Derifield) — PI 장골

소견

신전 시 짧았던 다리가 무릎 90도 굴곡 후 길어지거나 같아지는 반응 (crosses over).

변위

짧은 다리 쪽 장골의 후하방(PI, Posterior-Inferior) 변위를 시사한다.

기전 — 편심성 수축(Eccentric Contraction)

단계기전
① 장골 PI 변위장요근·대퇴직근·봉공근 등 고관절 굴곡근 약화
② 보상 반응해당 측 굴곡근 긴장도 증가 → 편심성 수축 상태 전환
③ 굴곡 시 반응이미 긴장된 굴곡근(대퇴직근·봉공근)이 더욱 당겨져 뻣뻣해짐
④ 하지장 변화골반에서 발을 더 높이 끌어올려 짧았던 다리가 길어 보임

교정 벡터: PSIS 하외측 접촉 → IS(하→상) + PA(후→전).

④ 음성 데리필드 (-D, Negative Derifield) — 회전 변위

소견

신전 시 짧았던 다리가 무릎 굴곡 후에도 짧거나 더 짧아지는 반응.

변위 의미

장골 또는 천골이 세로축(θY축)을 중심으로 회전하는 분절 기능장애를 시사한다 — EX/IN 장골, 천골 전방/후방 회전.

기전 — 동심성 수축(Concentric Contraction)

구분+D (양성)-D (음성)
변위 방향PI (후하방)AS / EX / IN / 천골 회전
근육 상태편심성 수축 (늘어나며 저항)동심성 수축 (짧아지며 당김)
굴곡 반응짧은 다리가 길어짐변화 없거나 더 짧아짐

⑤ 분리 검사 (Isolation Test / θY축 기능장애 검사)

음성(-D) 확인 후 EX·IN·천골 회전 중 정확한 방향을 두 그룹으로 좁히기 위해 시행한다.

  1. 술자는 검사 측 허벅지 높이에 서서 대각선 아래쪽을 바라본다.
  2. 환자에게 검사 측 무릎을 곧게 펴서 고정(lock)하도록 지시한다.
  3. 환자가 고관절을 신전시켜 다리를 끝 범위(end range)까지 들어 올린다.
  4. 술자가 수동으로 고관절을 약간 더 신전시켜 SIJ에 기계적 부하를 건다(engage).
  5. 다리를 내려놓고 신전 상태에서 짧은 다리가 여전히 짧은지 확인한다.
  6. 양 무릎을 90도 굴곡 후 반응 측 하지장 변화를 관찰한다.
굴곡 시 반응의미하는 변위 그룹
짧은 다리가 길어짐EX 장골(외회전) 또는 천골 후방 회전 (P-L/P-R)
짧은 다리가 더 짧아짐IN 장골(내회전) 또는 천골 전방 회전 (A-L/A-R)

⑥ 관절 압박 검사 (Articular Pressure Test) — 변위 확진

압박 후 신전·굴곡 모두에서 하지장이 동등해지면 해당 변위로 확진한다.

그룹 A — 분리 검사에서 길어진 경우 (EX 장골 vs 천골 후방 회전)

검사 순서접촉 부위압박 방향확진
① 천골 후방 회전 (먼저) 천골 익(Sacral ala) — 제1-2 천추 결절 외측, hypothenar 접촉 M→L + P→A (내측→외측, 후→전) 동등해지면 P-L/P-R 천골 확진
② EX 장골 (미해결 시) PSIS 하외측, pisiform 접촉 L→M + I→S (외→내, 하→상) 동등해지면 EX 장골 확진

그룹 B — 분리 검사에서 더 짧아진 경우 (IN 장골 vs 천골 전방 회전)

검사 순서접촉 부위압박 방향확진
③ IN 장골 (먼저) PSIS 내측 S→I + M→L (상→하, 내→외) arcing tissue pull 동등해지면 IN 장골 확진
④ 천골 전방 회전 (미해결 시) 서혜인대(Inguinal lig.) 중간 외측 — ASIS 아래 ~2인치 L→M (외→내) 동등해지면 A-L/A-R 천골 확진

⑦ 드롭 교정의 힘 — 관성·벡터·생리 효과

Newton 제1법칙 — 관성에 의한 HVLA

신체가 드롭 테이블과 함께 하강하다가 갑자기 정지할 때, 관성에 의해 뼈와 관절의 운동량은 수십 ms 동안 계속 진행하려 한다. 근육이 방어 수축하기 전에 운동 에너지가 관절에 직접 침투하여 교정 효과를 낸다. 결과적으로 표준 수기 추력보다 최대 30% 적은 압축력으로 동등한 관절 운동을 기대할 수 있다.

직선 벡터 원칙

비틀기(Twisting)·굴곡 벡터를 배제하고, 해부학적 관절면에 평행한 직선 벡터만 적용한다. 벡터가 관절면을 정확히 통과해야 주변 연부 조직의 에너지 흡수가 최소화된다.

생리·신경학적 효과

효과기전
기계수용기 자극Pacinian·Ruffini corpuscle + 근방추 빠른 활성화
패턴 차단(Pattern Interrupt)신경계 만성 과긴장 패턴 일시적 재설정
통증 억제척수 후각 gate control, DNIC 활성화
환자 협조 향상뒤틀림·꺾임 없어 방어 반사(Guarding) 감소

임상 적용

적응증

  • 기계적 요통·천장관절 통증·골반 부정렬
  • 표준 HVLA에 부담을 느끼는 환자(고령·골다공증 경향·체구가 큰 환자·통증 과민)
  • 흉추 분절 기능장애 — 흉추 drop은 비교적 안전하게 적용 가능
  • 경추는 lateral-prone 또는 supine cervical drop으로 변형 적용 가능(시술자 숙련도 필요)

환자 자세 · 접촉점 · 추력 벡터

  1. 자세 — 부위별 drop section 위에 표적 분절이 오도록 정렬. 요추·골반 drop은 prone, 경추는 lateral-prone, supine은 manual에서 다룸.
  2. 접촉점 — Listing에 따라 SP·TP·mammillary·PSIS. Pisiform이 가장 흔함.
  3. Drop 세팅 — 환자 체중·분절 깊이에 맞춰 드롭 텐션 조정. 너무 헐겁거나 너무 빡빡하면 안전·효과 모두 저해.
  4. 추력 벡터 — Listing 반대 방향, 디스크 평면에 평행. 짧고 빠른 체중 이동 + drop이 동조해야 함. 깊이가 아닌 속도로 만들기.
  5. 재평가 — 즉시 신경학적·기능적 재평가, 같은 분절 같은 세션 반복 추력 금지.

🔴 안전 · 금기 · 다학제 협진

금기

  • 절대 금기 — 진행성 신경학적 결손, CES, 진행성 골절·악성 종양·감염, 출혈 경향(INR 불안정), 동맥류, 임신 후기의 prone 자세.
  • 상대 금기 — 활동성 류마티스, 강직척추염, 최근 척추 수술 부위. 골다공증의 경우 drop의 분산 효과로 표준 HVLA보다 안전하나 여전히 신중함이 필요.
  • 안전 절차 — Drop 텐션 사전 확인, 환자 위치 잠금 확인, 추력 직후 재평가, 환자에게 'click' 음과 잠시의 압박감을 사전 설명.

🔗 다학제 협진

만성 요통·기능제한 환자에서는 운동치료·물리치료와 결합, 통증 양상이 비특이적이거나 red flag가 있으면 정형외과·신경외과·통증의학과로 의뢰. Drop technique은 도수치료의 한 자극 양식으로, 다학제 통합 치료의 한 요소로 위치시킵니다.
