# Week 2 — 분석과 진단 (Analysis & Diagnosis)

> **어디를 · 왜 · 어떻게 교정할지** 결정하는 임상 의사결정의 체계
> 한국 정형외과·재활의학과 의사 및 도수치료 훈련 물리치료사 대상

---

## 🎯 이 주차의 학습 목표

- **1.** Diversified HVLA 적용 전 반드시 수행하는 **4단계 평가 플로우**를 설명할 수 있다
- **2.** Red Flag 11가지를 구분하고 **응급 의뢰 의사결정**을 내릴 수 있다
- **3.** Motion Palpation의 **재현성 한계**를 알고 다른 검사와 조합 해석할 수 있다
- **4.** VBI(Vertebrobasilar Artery Insufficiency) 스크리닝을 **병력+검사+영상 조합**으로 수행할 수 있다
- **5.** ACR Appropriateness Criteria에 따른 **X-ray 적응증**을 구분할 수 있다

## 제1부. 환자 평가 4단계 플로우 {#part1}

### 1.1 전체 의사결정 알고리즘

```
[Step 1] Screening
   - Red Flag 유무 확인
   - Yes → 즉시 영상·전문의 의뢰 (교정 보류)
   - No → Step 2
     ↓
[Step 2] Diagnosis (진단)
   - 문진(OPQRST) + 관찰 + 촉진 + 정형·신경 검사
   - 생체역학적 문제인가? (분절 기능장애 여부)
     ↓
[Step 3] Analysis (분석)
   - 어느 분절 · 어느 방향 기능장애인가?
   - Motion Palpation + Static Palpation 일치 확인
     ↓
[Step 4] Planning (계획)
   - 환자 자세·접촉점·추력 벡터 결정
   - 치료 전 환자 동의 · 금기 최종 확인
```

### 1.2 각 단계의 소요 시간 (외래 기준)

| 단계 | 초진 | 재진 |
|------|------|------|
| Screening | 2-3분 | 30초 |
| Diagnosis | 15-20분 | 3-5분 |
| Analysis | 5-10분 | 2-3분 |
| Planning + 교정 | 3-5분 | 2-3분 |
| **합계** | **25-40분** | **8-12분** |

### 1.3 기록 의무 (의료법)

한국 의료법 제22조: 진료기록부 작성 의무. Diversified 교정도 동일 원칙 적용:
- 주 호소(CC) · 현병력(HPI) · 과거력(PMH)
- 시행 검사 결과 (수치·좌우 비교)
- 진단명 (ICD-10) · 교정 부위·기법
- 반응·부작용·계획

## 제2부. 문진 — OPQRST + Red Flag 스크리닝 {#part2}

### 2.1 OPQRST 완전판

| 항목 | 영문 | 내용 | Diversified 관련 힌트 |
|------|------|------|----------------------|
| **O** | Onset | 발병 시점·유발 상황 | 외상성 vs 점진성 구분 |
| **P** | Provoking / Palliating | 악화·완화 요인 | 자세 의존 → 기계적 |
| **Q** | Quality | 통증 성질 | Deep dull ache vs sharp shooting |
| **R** | Radiation | 방사 여부 | Dermatome 일치 여부 |
| **S** | Severity | 강도 (VAS/NPRS 0-10) | 초·후 재측정 기준선 |
| **T** | Timing | 24시간 양상·주기 | 야간통·기상 강직 → red flag 고려 |

### 2.2 Diversified 특이 문진 추가 항목

- **과거 척추 시술력** — 디스크 수술·척추 고정술·경추 융합술
- **Anticoagulant 복용** — Warfarin·DOAC (추력 후 출혈 위험↑)
- **Bone health** — 골다공증 진단·DEXA·장기 스테로이드 사용
- **VBI 증상 이력** — 5 Ds + 3 Ns (아래 VBI 섹션)
- **최근 외상** — 자동차 사고·낙상·스포츠 부상

### 2.3 🔴 Red Flag 11가지 (즉시 의뢰)

| # | Red Flag | 시사 병변 | 권장 조치 |
|:-:|----------|-----------|----------|
| 1 | 생애 첫 **가장 심한 두통** (thunderclap) | SAH · VAD | 즉시 ER → CT |
| 2 | **진행성 신경학적 결손** (근력 5→3 등) | Myelopathy · 종양 | 신경과 · MRI |
| 3 | **안장 마취**(saddle anesthesia) + 배변·배뇨 장애 | Cauda equina | 응급 MRI |
| 4 | **설명 안 되는 체중 감소** ≥ 5kg / 6개월 | Neoplasm | 영상 + 종양표지자 |
| 5 | **야간 통증 > 기상 통증** | 종양 · 감염 | MRI |
| 6 | **발열 + 척추 통증** | 감염 (discitis, osteomyelitis) | CRP · MRI with Gd |
| 7 | **외상 후 심한 경부통** + VBI 증상 | Vertebral artery dissection | CT angio · 즉시 |
| 8 | **50세 이상 초발 등통증** + 위험인자 | 압박 골절 · 전이 | X-ray · MRI |
| 9 | **스테로이드 장기 사용** + 척추통 | 병적 골절 | X-ray · DEXA |
| 10 | **면역억제** + 척추통 | 감염 | CRP · MRI |
| 11 | **자가면역질환 병력** (AS 등) | 강직척추염 | HLA-B27 · 영상 |

### 2.4 Red Flag 없음 확인 후 진행 원칙

- **교정 전** 마지막 확인: "지난 2주 내 새로운 증상 생겼나요?"
- Red Flag 발견 시 **교정 금지** · 해당 환자에게 이유 설명 · 의뢰 문서 작성

## 제3부. 관찰(Inspection) 시스템 {#part3}

### 3.1 전체 관찰 순서 (정중·측면·후면)

```
Standing Posture
 ├─ Anterior view: 머리 정렬·어깨 높이·팔 각도·슬개골·발 각도
 ├─ Lateral view: 두부 전방 위치·경추 lordosis·흉추 kyphosis·요추 lordosis·골반 tilt
 └─ Posterior view: 귀-어깨-ASIS 수직 정렬·흉추·요추 측만·하지 정렬
```

### 3.2 Plumb Line 기준 (ideal)

측면 기준:
- 외이도 → 어깨 견봉 → 대전자 → 외측 과 → 외과 앞 1cm
- 편차 측정: 두부 전방 위치(FHP), 골반 전·후경(anterior/posterior pelvic tilt)

### 3.3 병적 관찰 소견 → 가능 병변 매핑

| 관찰 소견 | 가능 병변 |
|-----------|----------|
| 고개가 한쪽으로 기울임 (torticollis) | 급성 경추 기능장애 · SCM 긴장 |
| 두부 전방 위치(FHP) >5cm | Forward head posture · 경추통 예측 |
| 흉추 과도 kyphosis | 골다공증·압박골절(50+) · Scheuermann's(청소년) |
| 요추 과도 lordosis | 과체중·임신·Lumbar 디스크 보상 |
| 골반 측방 기울임 | AS/PI 장골 · 기능적 단하지 |
| 슬개골 회전 | 고관절 회전 이상 |
| 발 외전·내전 | 근막 긴장 패턴 |

### 3.4 피부·연부조직 관찰

- **멍 · 반상출혈** → 외상·항응고제 복용
- **수술 흉터** → 과거 시술 확인
- **피부 변화** (café-au-lait, 색소 침착) → 전신 질환
- **부종** → 염증·심부전

## 제4부. Static Palpation {#part4}

### 4.1 Static Palpation의 정의

환자를 **정적(static)** 상태(보통 prone 또는 seated)에서 **촉지**하여:
- 분절 정렬(alignment)
- 연부조직 긴장(hypertonicity)
- 열(heat) · 종창(swelling)
- 압통(tenderness)

평가.

### 4.2 순서

1. **Superficial Touch** — 피부 온도·trophic 변화
2. **Light Palpation** — 표층 근 긴장
3. **Deep Palpation** — 관절·분절 정렬
4. **Landmark Comparison** — 좌우 대칭

### 4.3 부위별 주요 Landmark

| 부위 | 촉진 Landmark |
|------|---------------|
| 경추 | Mastoid · C1 TP · C2 spinous · C7 spinous (가장 돌출) |
| 흉추 | T3 (scapular spine 연결) · T7 (inferior scapular angle) · T12 (12번 늑골) |
| 요추 | L4 (iliac crest 연결) · L5 (PSIS 상방) · Mamillary processes |
| 천장 | PSIS · Sacral base · Sacral apex · Ischial tuberosity |

### 4.4 좌우 대칭 비교 — 핵심 원칙

각 랜드마크의 **좌우** 및 **상하** 관계를 **반드시 대칭 비교**:
- 대칭이면 정상
- 비대칭 + 통증 + Motion Palpation 이상 → 교정 대상
- 비대칭만 있고 무증상 + MP 정상 → **경과 관찰**

### 4.5 Static Palpation의 신뢰도

| 구조 | Intra-rater ICC | Inter-rater ICC |
|------|-----------------|-----------------|
| 극돌기 위치 | 0.5-0.7 | 0.3-0.5 |
| 압통 유무 | 0.7-0.9 | 0.5-0.7 |
| 근긴장 | 0.4-0.6 | 0.2-0.4 |

→ **Inter-rater reliability 제한적** — 항상 다른 검사와 조합 (5 Components 원칙 유사).

## 제5부. Motion Palpation — Diversified의 진단 핵심 {#part5}

### 5.1 정의와 임상적 위상

**Motion Palpation (MP)**: 분절별 **수동적 운동 범위·끝느낌(end-feel)**을 평가하여 기능장애 분절을 찾는 기법. Diversified 진단의 **가장 특징적** 절차.

### 5.2 MP 검사 방법 (부위별)

#### 경추 MP (환자 좌위 또는 앙와위)
1. 검사자가 환자 측두·후두부를 양손으로 잡는다
2. 각 경추 분절에 대해:
   - **굴곡·신전** 끝 움직임 평가
   - **좌·우 회전** (C1-C2 주로 여기)
   - **좌·우 측굴**
3. **Hypomobility** 또는 **Hypermobility** 구분
4. End-feel: soft (정상) / hard (관절 기능장애) / empty (통증으로 중단)

#### 흉추 MP (환자 prone 또는 seated)
1. 극돌기에 양 thumb contact
2. **PA 압박**(Posterior-Anterior spring test) — Maitland grades 적용
3. **회전** · **측굴** 분절 평가

#### 요추 MP
1. Side posture 또는 prone
2. PA spring test (grades I-IV)
3. **Flexion-Extension** 분절 움직임 평가
4. **Rotation** (side posture에서)

#### 골반 MP
1. **Gillet test** — 한 다리 들어올릴 때 PSIS 움직임
2. **ASIS 움직임** (supine, 다리 굴곡)
3. **Sacral respiratory motion** — 호흡 중 sacrum base 움직임

### 5.3 End-Feel 분류

| End-feel | 설명 | 시사점 |
|----------|------|--------|
| Soft (정상) | 부드러운 elastic 저항 | 정상 분절 |
| Firm (정상) | 약간 더 단단한 저항 | 정상 또는 경도 제한 |
| Hard (이상) | 갑작스런 저항 | Joint fixation · 관절염 |
| Empty (이상) | 환자가 통증으로 중단 | 염증 · 급성 병변 |
| Boggy (이상) | 물렁함·점성 | 부종·염증 |

### 5.4 MP의 재현성 한계 — Critical View

- **Inter-rater reliability ICC 0.2-0.5** (Seffinger 2004 systematic review)
- **훈련 시간**: 최소 100+ 시간 실습 필요 (student level)
- **표준화 부족**: 검사자마다 지표가 다름
- **🟡 결론**: MP 단독 진단 **근거 부족** → 반드시 **여러 검사 조합**(palpation · 정형 검사 · 영상)으로 확인

### 5.5 MP의 올바른 사용 — 본 강의 입장

- **제한 단독 도구**가 아닌 **선별(screening) 도구**
- 양성 소견 → 다른 평가(Motion X-ray, flexion-extension X-ray)로 확정
- MP + Static Palpation + 정형 검사 일치 시에만 교정

## 제6부. Postural Assessment — Plumb Line과 3D 정렬 {#part6}

### 6.1 정면 관찰 (Anterior View)

```
점검 항목:
 - 두부 중앙 정렬 (귀 하단 수평)
 - 어깨 높이 좌우 대칭 (보통 우측 3mm ↓ 허용)
 - ASIS 높이 좌우 대칭
 - 슬개골 방향 (정면 ± 10°)
 - 발 각도 (7-10° 외전 정상)
```

### 6.2 측면 관찰 (Lateral View)

**Plumb line**: 외이도 → 어깨 견봉 → 대전자 → 슬개골 앞연 → 외과 앞 1cm

| 편차 | 측정 | 병적 기준 |
|------|------|-----------|
| FHP (forward head posture) | 귀-어깨 거리 | &gt; 5cm = 병적 |
| Kyphosis | T1-T12 각도 | &gt; 40° (노인) / &gt; 50° (젊은) = 병적 |
| Lordosis | L1-L5 각도 | &lt; 40° or &gt; 65° = 이상 |
| Pelvic tilt | ASIS-PSIS 수평 비교 | &gt; 10° = 병적 |

### 6.3 후면 관찰 (Posterior View)

- 중앙 정렬 (occipital prot → C7 → L5 → anal cleft)
- 척추 측만(scoliosis) — Adam's forward bend test
- 견갑골 대칭·하각(inferior angle) 수평
- 둔부 fold 대칭

### 6.4 Cobb Angle 측정 (X-ray, 필요 시)

Scoliosis 판정:
- &lt; 10° — normal variation
- 10-19° — mild scoliosis
- 20-39° — moderate (보조기 고려)
- &gt; 40° — severe (수술 고려)

## 제7부. 신경학적 검사 프로토콜 {#part7}

### 7.1 경추 방사통 환자 — 상지 신경학

| 평가 항목 | 방법 | 분절 대표 |
|-----------|------|-----------|
| **감각** (light touch, pin prick) | 각 dermatome | C5: 삼각근 · C6: 엄지 · C7: 중지 · C8: 소지 · T1: 전완 내측 |
| **근력 (MMT 0-5)** | 저항 검사 | C5: 삼각근 · C6: 이두 · C7: 삼두 · C8: 수지 flexor |
| **심부건반사 (0-4+)** | 망치 | C5-6: biceps · C6: brachioradialis · C7: triceps |
| **병적 반사** | 당김 | Hoffmann (upper motor neuron) |

### 7.2 요추 방사통 — 하지 신경학

| 평가 | 방법 | 분절 |
|------|------|------|
| 감각 | Dermatome | L3: 전대퇴 · L4: 내측 · L5: 외측·엄지 · S1: 외측·새끼 |
| 근력 | MMT | L2-3: 고관절 굴곡 · L4: 족배굴 (ankle dorsiflexion) · L5: 엄지 신전 (EHL) · S1: 족저굴 (plantar flexion) |
| 반사 | 망치 | L4: patellar · S1: Achilles |
| 병적 반사 | 당김 | Babinski (upper motor neuron) |

### 7.3 Gait 검사

- 뒤꿈치 걷기 (heel walk) — L4-5
- 발끝 걷기 (toe walk) — S1-2
- Tandem gait — 소뇌·후주

### 7.4 특수 검사

#### 경추
- **Spurling test** — 동측 회전 + 측굴 + axial compression → 동측 방사통 재현 = 신경근 자극
- **Distraction test** — 경추 견인으로 증상 완화 → 신경근 압박
- **Shoulder abduction test** — 팔 올리면 편해짐 → C5-6 신경근

#### 요추
- **Straight Leg Raise (SLR)** — 30-70° 사이 방사통 = L5/S1 신경근 자극
- **Braggard sign** — SLR에서 증상 유발 후 족배굴 → 악화
- **Crossed SLR** — 반대 측 거상시 환측 통증 = 큰 디스크 병변 (낮은 민감도, 높은 특이도)
- **Slump test** — 앉은 자세, 경추 굴곡+SLR — 신경 긴장

## 제8부. 정형학적 특수 검사 {#part8}

> 각 검사마다 **방법 · 양성 소견 · 임상적 의의(진단) · 민감도/특이도 · 위양성 주의사항**을 정리합니다. 모든 검사는 단독으로 확진 불가 — **병력·영상·신경학 검사와 조합**해야 합니다.

### 8.1 경추 instability / VBI 검사

#### 🔵 Sharp-Purser Test — Transverse ligament (C1-C2) 안정성

- **방법**
  1. 환자 좌위, 약간 경추 굴곡 (30°)
  2. 검사자 한 손 **이마에 접촉** (Posterior 방향 지지)
  3. 다른 손 검지 · 중지로 **C2 극돌기 안정**
  4. 이마에 **서서히 posterior 압력** 가하며 환자 C1-C2 사이 슬라이딩 느낌
- **양성 소견**: Head가 posterior로 "slide" 되는 느낌 · 증상(어지럼·오심) 감소
- **임상적 의의**: Transverse ligament 이완·파열 → **C1-C2 instability** → 경추 HVLA **절대 금기**
- **민감도/특이도**: 민감도 88% · 특이도 96% (Uitvlugt 1988, RA 환자 연구)
- **위양성 / 주의사항**
  - 검사자 숙련도 높게 요구
  - 급성 외상 직후 시행 금지 — dens fracture 배제 먼저
  - **RA 환자의 스크리닝 도구**로 권장 (25% RA 환자에서 C1-C2 instability)

#### 🔵 Alar Ligament Stress Test

- **방법**
  1. 환자 좌위 또는 supine
  2. 검사자가 **C2 극돌기를 한 손으로 단단히 고정**
  3. 다른 손으로 **두부를 반대 방향으로 측굴**(lateral flex) 시키기
  4. C2가 즉시 함께 움직여야 정상
- **양성 소견**: **두부 측굴 시 C2가 함께 움직이지 않음** (지연 · 과도 움직임)
- **임상적 의의**: Alar 인대 손상 → 경추 회전 안정성 저하 → HVLA 금기
- **민감도/특이도**: 민감도 69% · 특이도 72% (Kaale 2008)
- **위양성 / 주의사항**
  - 환자 이완 불충분 → 근긴장으로 가짜 양성
  - 반대 측 alar ligament 손상 구분 어려움
  - **MRA/CTA** 의심 시 영상 확정 필수

#### 🔵 De Kleyn (Vertebral Artery) Test

- **방법**
  1. 환자 **supine**, 머리를 검사대 끝에
  2. 검사자가 두부를 양손으로 지지
  3. 한 쪽으로 **경추 회전 45° + 신전 20° 유지 30초**
  4. 반대 측도 동일
  5. 환자에게 증상(어지럼·복시·오심·nystagmus) 확인
- **양성 소견**: 자세 유지 중 VBI 증상(5Ds + 3Ns) 출현 · nystagmus 관찰
- **임상적 의의**: Vertebral artery 혈류 저하 의심 → 경추 HVLA 주의
- **민감도/특이도**: **민감도 매우 낮음 (&lt; 10%)** · 특이도 ~90% (Haynes 2002)
- **위양성 / 주의사항**
  - 위양성 많음: 내이성 어지럼·BPPV도 자세로 유발
  - 위음성도 많음 — 음성이어도 VAD 배제 불가
  - **단독 의존 금지** — 병력 + CTA/MRA 조합 필수
  - 현대 EBM에서는 이 검사의 routine 사용을 **권장하지 않음** (Kerry 2008)

#### 🔵 Barré-Liéou Test (Cervicogenic Dizziness)

- **방법**
  1. 환자 좌위, 머리 양측 회전 45°
  2. 각 방향 **30초 유지**
  3. 어지럼·nystagmus·오심 관찰
- **양성 소견**: 경추 회전 자세에서 어지럼 · nystagmus 유발
- **임상적 의의**: **경추성 어지럼** 의심 (cervicogenic vertigo). 단 단독으로는 BPPV와 감별 불가
- **민감도/특이도**: 제한된 연구 · ~30-50% 민감도
- **위양성 / 주의사항**
  - **BPPV** (특히 후반고리관)와 구분 어려움 → Dix-Hallpike 선행
  - 전정계 단독 문제일 수 있음
  - 경추성 어지럼은 **제외 진단(exclusion diagnosis)**

> ⚠ **경추 instability/VBI 검사군 전체의 임상적 가치**
> - 개별 검사의 민감도·특이도 모두 제한적
> - 의심 시 반드시 **CT angiography(CTA) 또는 MR angiography(MRA)** 추가
> - **환자 병력** (최근 두부 외상 · 어지럼 · 심혈관 위험인자)이 이들 검사보다 더 중요한 red flag

### 8.2 견관절 (Shoulder)

#### 🔵 Neer Impingement Test

- **방법**
  1. 환자 좌위
  2. 검사자 한 손 환자 **견갑골 고정**
  3. 다른 손으로 환자 팔을 **완전 내회전 + 전방굴곡(180°)** 시키기 (엄지가 아래로)
- **양성 소견**: 전방 견관절부 통증 유발
- **임상적 의의**: Subacromial impingement (supraspinatus · long head of biceps 건이 acromion 하에서 압박)
- **민감도/특이도**: 민감도 72-79% · 특이도 31-60% (다양한 meta-analysis)
- **위양성 / 주의사항**
  - **특이도 낮음** → 오진 흔함 (단독으로 확진 불가)
  - Rotator cuff tear, AC joint OA, 점액낭염도 양성 가능
  - 영상 (MRI · ultrasound)로 감별 필요

#### 🔵 Hawkins-Kennedy Test

- **방법**
  1. 환자 좌위
  2. 환자 팔을 **전방굴곡 90° + 주관절 굴곡 90°**
  3. 검사자가 **수동적으로 내회전** 시킴
- **양성 소견**: 견관절 통증 재현
- **임상적 의의**: Subacromial impingement (greater tuberosity와 coracoacromial ligament 사이 압박)
- **민감도/특이도**: 민감도 79% · 특이도 59% (Calis 2000)
- **위양성 / 주의사항**
  - Neer test와 유사 — 구조 특이성 낮음
  - 두 검사 **동시 양성** → 특이도 증가 (combined 89%)
  - Rotator cuff tear과 구분 위해 **Empty Can** 병행

#### 🔵 Empty Can Test (Jobe's Test)

- **방법**
  1. 환자 좌위, 양팔 **scapular plane**(정면에서 약 30° 앞쪽)으로 90° 외전
  2. 엄지가 **아래로 향하도록** (빈 캔 거꾸로 드는 자세)
  3. 검사자가 **아래 방향으로** 저항 압력
  4. 환자는 팔을 들어올리도록 저항
- **양성 소견**: 통증 또는 근력 약화 (3/5 이하)
- **임상적 의의**: Supraspinatus 건 병변 (tendinopathy · 부분/완전 파열)
- **민감도/특이도**: 민감도 69% · 특이도 62% (Park 2005)
- **위양성 / 주의사항**
  - 경부 방사통도 양성 가능 (C5 신경근)
  - Subacromial 점액낭염으로 통증만 — 실제 건 병변 없을 수 있음
  - MRI·초음파로 확진

#### 🔵 Apprehension Test (Anterior Shoulder Instability)

- **방법**
  1. 환자 **supine** 또는 좌위
  2. 검사자가 환자 팔을 **외전 90° + 외회전** 시키기
  3. 서서히 외회전 증가
- **양성 소견**: 환자가 **"빠질 것 같다"**는 공포(apprehension) 호소 (단순 통증이 아닌 불안)
- **임상적 의의**: 전방 견관절 불안정 (anterior labral tear, Bankart lesion)
- **민감도/특이도**: 민감도 53% · 특이도 99% (Farber 2006) — **특이도 매우 높음**
- **위양성 / 주의사항**
  - 통증만 호소 → 양성 아님 (공포 · 불안이 핵심)
  - Relocation test 병행 (posterior pressure로 완화) → 더 특이적
  - 최근 탈구 병력 환자 양성이 더 명확

### 8.3 고관절·골반 (Hip & Pelvis)

#### 🔵 FABER (Patrick's) Test

- **방법**
  1. 환자 **supine**
  2. 검사 측 다리 **외측 발목을 반대측 무릎 위**에 올림 (Figure-4 자세)
  3. 검사자가 **검사 측 무릎을 바닥 쪽으로 압력**
  4. 환자 반대측 ASIS 고정
- **양성 소견**
  - **Anterior groin pain** → hip joint 병변
  - **Posterior SI joint pain** → SI joint 병변
  - Knee가 반대측 대비 **높이 유지** → hip 제한
- **임상적 의의**: FABER = **F**lexion + **AB**duction + **E**xternal **R**otation. Hip joint 병변 (OA, labral tear) 또는 SI joint 병변 선별
- **민감도/특이도** (SI joint 병변)
  - 민감도 57% · 특이도 71%
  - 3개 이상 pelvic pain provocation test 양성 시 민감도 94% (Laslett 2005)
- **위양성 / 주의사항**
  - Adductor 단축 · knee 병변도 양성
  - **위치 특이성 중요** — "어디가 아픈지" 환자에게 명확히 물어보기
  - Hip OA 환자 routinely 양성

#### 🔵 Gaenslen's Test

- **방법**
  1. 환자 **supine**, 엉덩이를 검사대 가장자리
  2. 비검사 측 **무릎을 가슴 쪽으로 굴곡** (환자가 잡도록)
  3. 검사 측 다리는 **검사대 밖으로 걸쳐 떨어뜨려 신전**
  4. 검사자가 검사 측 무릎에 **하방 압력** (SI 회전 stress)
- **양성 소견**: 검사 측 SI joint 부위 통증 재현
- **임상적 의의**: SI joint dysfunction (ligamentous stress test)
- **민감도/특이도**: 민감도 53% · 특이도 71% (Laslett 2005 — 단독)
- **위양성 / 주의사항**
  - Hip OA 환자 — 신전으로 양성
  - L5-S1 facet 자극도 양성
  - **복합 검사군 (cluster)**으로 판정 필수: FABER + Gaenslen + Distraction + Compression + Thigh Thrust 중 **3개 이상 양성** = 진단 가치 ↑

#### 🔵 Thomas Test (Hip Flexor 단축)

- **방법**
  1. 환자 **supine**, 검사대 끝 엉덩이
  2. 비검사 측 무릎을 **가슴으로 완전 굴곡**하고 환자가 잡음 (요추 lordosis 제거)
  3. 검사 측 다리는 **자유롭게 늘어뜨림**
- **양성 소견**
  - 검사 측 대퇴가 **검사대에서 들림** (무릎이 검사대 위로) = hip flexor 단축
  - 무릎이 90° 이상 신전 = rectus femoris 단축
  - 대퇴 외전 시 = IT band 긴장
- **임상적 의의**: Hip flexor (iliopsoas, rectus femoris) 단축 평가
- **민감도/특이도**: 임상적 관찰 중심 · 정량 연구 제한
- **위양성 / 주의사항**
  - 환자가 lordosis를 제대로 평평하게 못 유지 → 가짜 양성
  - 골반 비대칭 · 요추 자세로 해석 오류 가능
  - Modified Thomas Test (무릎 굴곡 각도 측정) 더 정량적

#### 🔵 Trendelenburg Sign

- **방법**
  1. 환자 **standing**
  2. 검사자가 환자 뒤에서 PSIS 관찰
  3. 환자에게 **한 다리로 서도록** 지시 (30초)
  4. 양측 시행
- **양성 소견**: 서 있는 측 **반대쪽 골반이 아래로 떨어짐** (contralateral pelvic drop &gt; 2cm)
- **임상적 의의**: 서 있는 측 **gluteus medius 약화** (반대쪽 골반을 잡아주지 못함)
- **민감도/특이도**: 민감도 55-72% · 특이도 70-77% (Youdas 2010, hip OA)
- **위양성 / 주의사항**
  - 통증으로 인한 회피 자세 (antalgic) → 양성처럼 보일 수 있음
  - 아동·고령에서 균형 문제로 구분 어려움
  - **Delayed Trendelenburg** (20-30초 후 drop) → 진성 glut med 약화 지표

### 8.4 요추·골반 (Lumbar & Pelvis)

#### 🔵 Kemp Test (Quadrant Test)

- **방법**
  1. 환자 좌위 또는 기립
  2. 검사자가 환자 뒤에서 어깨 양측 고정
  3. 환자를 **신전 + 동측 측굴 + 동측 회전**으로 유도 (한쪽 quadrant로)
  4. 양측 모두 시행
- **양성 소견**: 동측 요추·하지 통증 재현
- **임상적 의의**: Lumbar **facet joint 자극** (posterior element) 또는 foraminal stenosis
- **민감도/특이도**: 민감도 40-75% · 특이도 63-85% (facet 주사 비교연구)
- **위양성 / 주의사항**
  - Discogenic pain도 양성
  - **Hip 병변** (특히 OA) 감별 어려움
  - 구조 특이성 낮음 → 진단은 조합 + 영상

#### 🔵 Quadrant Test (Combined Motion)

- **방법**
  1. 환자 기립
  2. **4 방향** 복합 움직임 각각 유지 (각 5초)
     - 신전 + 우측 측굴 + 우측 회전
     - 신전 + 좌측 측굴 + 좌측 회전
     - 굴곡 + 우측 측굴 + 우측 회전
     - 굴곡 + 좌측 측굴 + 좌측 회전
- **양성 소견**: 특정 quadrant에서 통증·방사통 재현
- **임상적 의의**
  - **신전 quadrant 양성** → facet joint 또는 foraminal stenosis
  - **굴곡 quadrant 양성** → disc · posterior ligament · hamstring 긴장
- **민감도/특이도**: Kemp test와 유사 (구조 특이성 낮음)
- **위양성 / 주의사항**
  - 만성 보상 자세로 비특이적 양성 흔함
  - **어느 방향에서 어느 통증인가** 구체 기록 필수

#### 🔵 Heel Drop Test (Percussion Test)

- **방법**
  1. 환자 기립, **발꿈치 든 상태**
  2. 검사자가 "탕!" 하고 **발꿈치를 떨어뜨리도록** 지시 (또는 검사자가 발꿈치를 두드림)
  3. 반복 3-5회
- **양성 소견**: 척추·골반 부위 **날카로운 통증 / 심한 악화**
- **임상적 의의**: **척추 골절 · 종양 · 감염** 의심 (axial loading시 병적 반응)
- **민감도/특이도**: 민감도 87% · 특이도 99% — 압박골절 (Markey 2015, 급성 외상)
- **위양성 / 주의사항**
  - **Red flag screening** 성격 — 양성 시 즉시 영상
  - Hip OA·무릎 OA 환자 주의 (과도한 force 위험)
  - 음성이어도 만성 골절 배제 불가

### 8.5 말초 신경·관절 (Peripheral Nerves & Joints)

#### 🔵 Phalen's Test (Carpal Tunnel Syndrome)

- **방법**
  1. 환자 좌위
  2. 양 손목을 **최대 굴곡**으로 유지 (손등끼리 맞댐)
  3. **60초 유지**
- **양성 소견**: 정중신경 분포부 (엄지·2·3·4지 요측) 저림·통증
- **임상적 의의**: 손목관 증후군 (median nerve compression)
- **민감도/특이도**: 민감도 68% · 특이도 73% (meta-analysis, McCartney 2013)
- **위양성 / 주의사항**
  - 숙련도·유지 시간에 따라 결과 차이
  - 경추 C6 신경근 증상과 감별 어려움
  - **EMG/NCS** 로 확진

#### 🔵 Tinel's Sign (at Wrist)

- **방법**
  1. 환자 좌위, 손목 신전
  2. 검사자가 **정중신경 위 (palmar wrist crease)**를 반사 망치로 가볍게 **타진**
  3. 2-3회 반복
- **양성 소견**: 정중신경 분포부 저림 · "전기" 감각
- **임상적 의의**: 손목관 증후군 · 신경 irritation
- **민감도/특이도**: 민감도 50% · 특이도 77% — 낮은 감도
- **위양성 / 주의사항**
  - **위양성 흔함** — 건강인도 10-15%에서 양성
  - Phalen과 조합 (두 검사 모두 양성 시 의심도 상승)
  - Ulnar nerve (엄지 내전근) Tinel도 별도 검사

#### 🔵 McMurray Test (Meniscus)

- **방법**
  1. 환자 **supine**
  2. 검사자가 **발목을 잡고**, 다른 손으로 **knee의 medial + lateral joint line 촉진**
  3. **무릎을 완전히 굴곡** (엉덩이 포함)
  4. 내측 반월판 검사: **외회전 + 외반** → 서서히 신전
  5. 외측 반월판 검사: **내회전 + 내반** → 서서히 신전
- **양성 소견**
  - 관절선에서 **"딸깍"(click) 소리** + 통증 재현
  - 신전 중 관찰되는 catching/locking
- **임상적 의의**: 반월판 파열 (meniscal tear)
- **민감도/특이도**: 민감도 55% · 특이도 77% (Scholten 2001)
- **위양성 / 주의사항**
  - Click 많은 위양성 (일반 관절 crepitus)
  - 통증 + click **조합** 요구 (Wright 강제)
  - MRI 확진이 gold standard

#### 🔵 Apley's Test (Meniscus Compression/Distraction)

- **방법**
  1. 환자 **prone**, 무릎 90° 굴곡
  2. **Compression phase**: 발바닥에 **하방 압력** + 회전
  3. **Distraction phase**: 발바닥에 **상방 견인** + 회전
- **양성 소견**
  - Compression에서 통증 → **meniscal lesion**
  - Distraction에서 통증 → **ligamentous lesion**
- **임상적 의의**: Meniscus vs ligament 감별
- **민감도/특이도**: 민감도 13% · 특이도 90% (meta-analysis)
- **위양성 / 주의사항**
  - **민감도 매우 낮음** (위음성 많음)
  - 특이도는 좋아 양성 시 의미 있음
  - McMurray와 병행 권장

#### 🔵 Anterior Drawer Test (Ankle)

- **방법**
  1. 환자 **supine** 또는 좌위, 무릎 살짝 굴곡
  2. 한 손으로 **하퇴 원위 고정**
  3. 다른 손으로 **calcaneus를 잡고 anterior로 당김**
  4. 족관절을 20° 족저굴곡 상태로 (ATFL 긴장 위치)
- **양성 소견**: 반대측 대비 **과도한 anterior 이동** (&gt; 5mm), soft end-feel
- **임상적 의의**: **Anterior talofibular ligament (ATFL)** 손상
- **민감도/특이도**: 민감도 96% · 특이도 84% (급성) — 시간 지나면 감소
- **위양성 / 주의사항**
  - 급성 종창·통증 — 환자 이완 어려워 과소 평가
  - **Squeeze test**로 syndesmosis 배제
  - 비교 대측 반드시 동일 조건

#### 🔵 Posterior Drawer Test (Ankle or Knee)

- **Ankle 방법**
  1. 환자 좌위, 무릎 90° 굴곡
  2. 한 손으로 **하퇴 고정**
  3. 다른 손으로 **calcaneus를 뒤로** 민다
- **Knee 방법**
  1. 환자 supine, 무릎 90° 굴곡
  2. 검사자가 환자 발 위에 앉아 고정
  3. 양손으로 **경골 상단을 뒤로** 민다
- **양성 소견**: 과도한 **posterior translation**, soft end-feel
- **임상적 의의**
  - Ankle: Posterior talofibular ligament · posterior capsule 손상 (매우 드묾)
  - Knee: **PCL (posterior cruciate ligament)** 손상
- **민감도/특이도** (PCL): 민감도 90% · 특이도 99% (Rubinstein 1994)
- **위양성 / 주의사항**
  - "Sag sign" (중력으로 경골 후방 이동) 먼저 관찰 — PCL 손상 간접 지표
  - 급성기 환자 이완 불충분 → 과소 평가

### 🟡 특수 검사군 총괄 — "Cluster Approach" 원칙

개별 검사의 민감도·특이도가 제한적이므로 **복합 검사군(cluster)**으로 진단 가치 증대:

| 부위 | Cluster | 진단 |
|------|---------|------|
| **SI joint** | FABER + Gaenslen + Compression + Distraction + Thigh Thrust — 5개 중 3+ 양성 | 민감도 94% · 특이도 78% (Laslett 2005) |
| **Cervical radiculopathy** | Spurling + Distraction + Shoulder abduction + ULTT — 3+ 양성 | Specificity 99% (Wainner 2003) |
| **Lumbar radiculopathy** | SLR + Crossed SLR + 감각·근력 결손 + reflex 변화 | 양성 2+ → 민감도 77% · 특이도 58% |
| **Rotator cuff tear** | Painful arc + Empty can + External rotation lag — 3개 양성 | 민감도 97% · 특이도 83% |

### 🔴 검사 단독 의존 금지 — 원칙

1. **병력 (History)** 이 가장 중요 — 검사는 확인 도구
2. **영상(X-ray, MRI, CTA)** 과 **임상 검사** 반드시 조합
3. 특이도 높은 검사(Apprehension, Anterior Drawer 등)도 **단독 진단 금지**
4. 위양성 흔한 검사(Neer, Hawkins, Phalen, Tinel)는 **cluster**로 해석
5. 검사 결과는 **좌우 비교** + **증상 재현 일관성** 중심으로 판정

## 제9부. Red Flags — 응급 의뢰 의사결정 {#part9}

### 9.1 Red Flag 재확인 (2주 카운선 원칙)

Diversified 시술 **2주 이상** 간격이 있었으면 반드시 **Red Flag 전체 재질문**. 환자가 그 사이 새 증상 발생했을 가능성.

### 9.2 분야별 의뢰 경로

| Red Flag 양성 | 의뢰 |
|---------------|------|
| 신경학적 결손 급성 | 신경과 응급 · MRI |
| 감염 의심 (발열+척추통) | 감염내과 / 정형외과 · MRI with Gd |
| 종양 의심 (체중감소·야간통) | 종양내과 / 정형외과 · MRI · PET |
| 혈관 의심 (VAD·SAH) | 응급실 · CT/MRA |
| 골절·탈구 (외상) | 정형외과 · X-ray·CT |

### 9.3 의뢰 문서 필수 항목

1. 환자 기본 정보 (이름·연락처·생년월일)
2. 현재 증상 요약 · 발병 시점
3. 수행한 검사 결과 (양성 소견 포함)
4. 의뢰 사유 (구체적으로)
5. 시급도 (emergency / urgent / routine)
6. 작성자 정보 · 날짜 · 서명

## 제10부. VBI(Vertebrobasilar Artery Insufficiency) 스크리닝 {#part10}

### 10.1 VBI의 임상적 중요성

Cervical manipulation 후 **vertebral artery dissection(VAD)** 위험이 과거 우려되었으나, 최신 연구(Cassidy 2008 등)는 SMT와 VAD의 **인과 관계보다 우연성**이 높다고 결론. 그럼에도 **스크리닝 필수**.

### 10.2 5 Ds + 3 Ns (VBI 증상)

| 기호 | 증상 |
|:-:|------|
| D | **D**izziness (어지럼) |
| D | **D**iplopia (복시) |
| D | **D**rop attacks (갑작스런 무력감) |
| D | **D**ysarthria (조음 장애) |
| D | **D**ysphagia (연하 장애) |
| N | **N**ausea (오심) |
| N | **N**ystagmus (안진) |
| N | **N**umbness (facial 감각 이상) |

**5 Ds + 3 Ns 중 2개 이상** 과거력·현재 증상 → 경추 Diversified **상대 금기**.

### 10.3 VBI 검사의 현재 권장

- **과거의 de Kleyn-Nieuwenhuyse test** (경추 회전+신전 30초) — 민감도 낮음. 단독 의존 금지.
- **Current evidence-based approach**:
  1. 상세 병력 (최근 외상 · 두통 · dissection 위험인자)
  2. 5 Ds + 3 Ns 질문
  3. 의심 시 **CTA 또는 MRA 권고** (교정 전)
  4. 젊은 환자 + 갑작스런 경부통 + 어지럼 → **즉시 응급**

### 10.4 Ciervical Manipulation 시 주의

- 회전 범위 최소화 (환자가 편한 범위 내)
- "Sustained pre-tension" 금지 (quick low-amplitude 원칙)
- 첫 시술 시 **low force** 시도
- 교정 후 즉시 5 Ds + 3 Ns 재확인

## 제11부. X-ray 적응증 · ACR 가이드라인 {#part11}

### 11.1 ACR Appropriateness Criteria (2023)

**Low Back Pain (ACR)**:
- **초진 단독 요통** + Red Flag 없음 + &lt; 6주 → **영상 검사 불필요** (usually not appropriate)
- **Red Flag 양성 또는 6주 이상 지속** → X-ray · MRI 고려
- **신경근 증상 + 수술 고려** → MRI

**Cervical Pain**:
- Red Flag 없음 + 단순 통증 → **영상 불필요**
- 외상 후 → Canadian C-spine rule 적용
- 방사통 6주 이상 → MRI

### 11.2 Canadian C-Spine Rule (외상)

**3 High-risk factors** → 즉시 X-ray:
1. 65세 이상
2. Dangerous mechanism (fall &gt; 1m, MVA &gt; 100km/h)
3. Paresthesias in extremities

**5 Low-risk factors** (모두 있어야 영상 생략 가능):
1. Simple rear-end collision
2. Patient sitting in ER
3. Ambulatory since injury
4. No midline C-spine tenderness
5. Delayed onset of neck pain

+ 45° 양측 회전 가능해야 함.

### 11.3 NICE Guideline for Acute Low Back Pain

- **&lt; 6주** + Red Flag 없음 → 영상 권장 안 함
- Red Flag → 영상 + 의뢰
- Radiculopathy 지속 → MRI (디스크 탈출 의심)
- Osteoporosis 의심 + fragility fracture → X-ray + DEXA

### 11.4 Gonstead vs 현대 EBM X-ray 사용

- **Gonstead 전통**: 전장척추 routine X-ray
- **현대 EBM**: 임상 지표 기반 선택적 영상
- **본 강의 입장**: Red Flag + 외상 + 6주 이상 지속 시에만 X-ray
- 환자 피폭 최소화 · 임산부·소아 회피

### 11.5 X-ray 해석 — Diversified 관점

- **전장(full spine)** — Cobb angle · pelvic obliquity · leg length 평가
- **Lateral Cervical** — lordosis · ADI · 추체 정렬
- **Lateral Lumbar** — disc height · wedging · spondylolisthesis
- **A-P Pelvis** — femoral head 대칭 · SI joint 간극 · ilium 높이

## 📝 시뮬레이션 케이스 5개 {#cases}

### Case 1. 45세 남성, 급성 요통

**CC**: 3일 전 무거운 물건 들다가 심한 요통. 우측 하지로 방사.
**PE**:
- SLR 우측 40°에서 양성 (dermatome L5)
- Motion palpation L4-5 우측 hypomobile
- 감각·근력 정상, 반사 정상
- Red Flag 모두 음성

**진단**: 기계적 요통 + L5 신경근 자극 (가벼운)
**계획**: Diversified L5 교정 + 휴식·아이싱 교육. 2주 후 재평가. 영상 유보.

### Case 2. 32세 여성, 경부통·어지럼

**CC**: 1주 전부터 경부통 + 어지럼. 목 돌릴 때 심함.
**PE**:
- VBI 질문: **dizziness (D) + nausea (N)** 양성 (2/8)
- 최근 2개월 내 외상 없음
- Hoffmann 음성

**의사결정**: VBI 2개 양성 → **경추 Diversified 보류**. 이비인후과 + 신경과 consult. Vestibular assessment 우선.

### Case 3. 68세 남성, 흉추통 + 야간통

**CC**: 2개월간 점진적 등 통증, 밤에 깨어날 정도. 기침 시 악화.
**PE**:
- 야간통 > 기상통 **(Red Flag #5)**
- 체중 4kg 감소 (6개월)  **(#4)**
- 흡연 40갑년 이력
- Motion palpation 정상

**의사결정**: **즉시 교정 금지**. MRI + 종양 스크리닝 (흉부 CT). 폐종양 척추 전이 감별.

### Case 4. 28세 여성, 경추통 + 두통

**CC**: 사무직, 2년간 반복되는 경부통·후두통. 컴퓨터 작업 후 심화.
**PE**:
- FHP 7cm (forward head posture)
- C1-C2 회전 우측 hypomobile, 좌측 정상
- C7 spinous tenderness
- 신경학 정상, Red Flag 모두 음성

**진단**: Cervicogenic headache · 기계적 경추통
**계획**: C1-C2 Diversified + 자세 교정·ergonomics 교육. 2주 후 재평가.

### Case 5. 55세 남성, 외상 후 경부통 + 저림

**CC**: 1주 전 자동차 후방 추돌 (whiplash). 이후 경부통 + 우측 상지 저림.
**PE**:
- Spurling test 우측 양성
- C6 dermatome 감각 감소 · biceps reflex 감소
- 경추 양측 회전 40° 제한

**의사결정**: Canadian C-Spine Rule 적용 → **X-ray 필요** (외상 후 + 양성 neurological). MRI 고려 (방사통). Diversified 보류까지.
