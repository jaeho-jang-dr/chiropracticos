# Week 4 — 임상 적용과 안전 (Clinical Application & Safety)

> 근거 기반 · 통합 치료 · 한국 임상 현장 적용
> Diversified HVLA를 **실제 환자**에게 쓰기 위한 최종 단계

---

## 🎯 이 주차의 학습 목표

- **1.** Diversified HVLA의 **근거 피라미드**를 적응증별로 설명할 수 있다
- **2.** 요통·경추통·두통에 대한 **임상 프로토콜**을 조합할 수 있다
- **3.** **절대·상대 금기**를 11+9가지 항목으로 식별할 수 있다
- **4.** Post-adjustment soreness 발생 시 **대응 프로토콜**을 실행할 수 있다
- **5.** 정형외과·재활의학과·도수치료 팀 내에서 **협진 결정**을 할 수 있다

## 제1부. 근거 피라미드 — Diversified 근거 수준 정리 {#part1}

### 1.1 Evidence Pyramid

```
               ┌──────────────────┐
               │   Systematic     │  Cochrane · meta-analysis
               │    Reviews       │
               ├──────────────────┤
               │    RCT           │  randomized controlled trials
               ├──────────────────┤
               │   Cohort /       │  prospective · case-control
               │  Case-control    │
               ├──────────────────┤
               │   Case series /  │  clinical reports
               │   Expert opinion │
               └──────────────────┘
```

### 1.2 Diversified/SMT 적응증별 근거 수준

| 적응증 | 근거 수준 | 대표 연구 |
|--------|-----------|-----------|
| **급성 기계적 요통** | 🟢 Strong | Paige 2017 JAMA · Cochrane 2012 |
| **만성 기계적 요통** | 🟡 Moderate | Rubinstein 2019 BMJ · Chou 2017 Ann Intern Med |
| **기계적 경추통** | 🟡 Moderate | Gross 2015 Cochrane |
| **Cervicogenic headache** | 🟡 Moderate | Chaibi 2019 Cochrane · Nilsson 1997 |
| **Tension-type headache** | 🟠 Limited | Moore 2017 BMC Musculoskelet Disord |
| **요추 disc herniation (비수술 후보)** | 🟡 Moderate | Peterson 2013 · Leeman 2014 |
| **어깨·팔꿈치·족부 mobilization** | 🟠 Limited | Piva 2004 · 개별 증례 |
| 🔴 **고혈압·천식·소화기·ADHD** | 🔴 No evidence | 부정적 · 비판적 언급만 |
| 🔴 **Vitalism-based systemic disease** | 🔴 No evidence | 근거 없음 |

### 1.3 EBM에서 Diversified의 위치

- **보조 치료(adjunctive)**가 현대 EBM 주류: 운동치료·교육과 **병행**
- SMT 단독 치료는 자주 사용되지만, **다학제 접근**이 권장
- 2017 Ann Intern Med (ACP 가이드라인): **급성 요통 — non-pharmacologic 1차**, SMT 포함

## 제2부. 요통 임상 프로토콜 {#part2}

### 2.1 급성 요통 (&lt; 6주)

#### Step 1. Screening
- Red Flag 11가지 확인 → 음성이면 진행
- VAS 0-10 기록 (baseline)

#### Step 2. Assessment
- Motion Palpation L1-S1
- SLR (신경근 증상 배제)
- Hip · SI joint special tests

#### Step 3. Treatment 초기 2주
- **1주차**: Diversified × 2-3회 (격일)
  - 환자 편한 자세 (side posture 대부분)
  - L4-5 or L5-S1 mobilization 주로
  - Low force 시작 → 환자 반응 확인
- **2주차**: Diversified × 1-2회 + 운동 (McKenzie · coreabilization)

#### Step 4. 경과 평가
- 4-6주 내 50% 통증 감소가 목표
- 호전 없음 → MRI · 전문의 의뢰

### 2.2 만성 요통 (> 12주)

- Diversified 단독 효과 **제한적** → **병행** 필수
- Protocol:
  - Diversified × 1/주 × 4-6주
  - + Core stability exercise
  - + Education (통증 교육, 자세 코칭)
  - + CBT (인지행동 치료) 고려
- 심리·사회 요인 평가 (STarT Back Tool)

### 2.3 Radicular Pain (방사통)

- Straight leg raise 양성 + 신경학적 결손
- **First-line**: 보존 치료 + Flexion-distraction (Cox 기법, Diversified 변형)
- Diversified HVLA L5-S1에서 **방사통 악화** 시 즉시 중단
- 6주 후 호전 없음 → MRI 추천

### 2.4 Pregnancy-related Low Back Pain

- **임신 중 Diversified는 가능** — side posture + 골반 쿠션
- Absolute 금기는 아님, 다만 force 조절 · 복부 압박 회피
- 후기 임신 (28주+): Webster technique 선호 (Diversified 변형)

## 제3부. 경추통·두통 임상 프로토콜 {#part3}

### 3.1 기계적 경추통

#### 초진
1. Red Flag + VBI 5Ds+3Ns 확인
2. Cervical range of motion 측정
3. Neurological 전 상지 evaluation
4. Spurling / Distraction / Shoulder abduction tests

#### 치료
- Diversified 경추 (C3-C7 우선, C1-C2는 숙련자)
- Force 조절 — 요추 대비 **저 force** (100-300N)
- 회전 범위 30°까지만 (VAD 위험 감소)
- 주 1-2회 × 4주

### 3.2 Cervicogenic Headache

- **특징**: 단측 두통, 경부 운동으로 악화, 압통점 C1-C2
- **Diversified**: C1-C2 우선, suboccipital mobilization 병행
- 근거: Nilsson 1997 (SMT + exercise 통증 감소)

### 3.3 Tension-type Headache

- **Diversified 단독 근거 🟠 Limited**
- 보통 upper thoracic + cervical 병행 교정 + 이완 훈련
- 약물 남용 두통 배제

### 3.4 Whiplash (외상성 경부 손상)

- **급성기 (1-2주)**: Diversified 삼가, soft collar + NSAID
- **아급성 (3-6주)**: 저force Diversified 가능, motion 회복 목적
- **만성 (>12주)**: 조심스런 HVLA + 운동 병행

### 3.5 Migraine

- **Diversified 단독 근거 🟠**
- Trigger 회피·생활습관·약물 동시
- 일부 환자에서 경추 factor 존재 시 효과 있을 수 있음

## 제4부. 사지 관절 임상 적용 {#part4}

### 4.1 Shoulder Impingement

- Diversified AC joint mobilization
- Glenohumeral posterior glide
- Rotator cuff strengthening exercise 병행
- 4-6주 프로토콜

### 4.2 Lateral Epicondylopathy (Tennis Elbow)

- Radial head mobilization
- Wrist extensor soft tissue work
- Eccentric exercise 병행

### 4.3 Carpal Tunnel Syndrome (mild to moderate)

- Carpal bone mobilization
- Neural mobilization (median nerve glide)
- Ergonomic education
- 중증 (EMG 확정) → 외과 의뢰

### 4.4 Knee Osteoarthritis

- Patellar mobilization · tibiofemoral distraction
- Quadriceps 강화 운동 병행
- Severe → 정형외과 (인공관절 고려)

### 4.5 Ankle Sprain (chronic instability)

- Talocrural distraction + subtalar mobilization
- Proprioceptive training
- 급성 부상 (48시간 이내) → PRICE + 의사 평가

### 4.6 Plantar Fasciitis

- Cuboid whip · talocrural mobilization
- Calf stretching + eccentric
- Night splint 고려

## 제5부. 안전성 통계 — VAD · 부작용 관리 {#part5}

### 5.1 Vertebral Artery Dissection (VAD)

#### 발생률
- SMT 후 VAD: **1 per 5.85 million** cervical manipulations (Cassidy 2008)
- 일반 인구 VAD: 1-1.5 per 100,000/year
- SMT와 VAD 사이 **인과 관계 입증 안 됨** — 오히려 "두통·경부통 + 이미 시작된 VAD 환자가 SMT 받으러 옴" 패턴

#### 예방
- 5 Ds + 3 Ns 스크리닝
- 최근 외상력 확인
- 급성 경부통 + neurological sign → SMT 미뤄
- Low-force · rotation 최소화

### 5.2 일반 부작용 (흔함)

| 부작용 | 빈도 | 관리 |
|--------|------|------|
| Soreness / stiffness | 30-60% (24-48h) | 아이싱 · 정상 |
| 두통 | 5-10% | 휴식 · 수분 · 24h 내 소실 보통 |
| 피로 | 5-15% | 안심 · 24h 내 회복 |
| 어지럼 (경도) | 2-5% | 관찰, 심하면 중단 |

### 5.3 드문 · 심각 부작용

| 부작용 | 빈도 |
|--------|------|
| Cauda equina syndrome | < 1 per 100만 (매우 드묾) |
| Vertebral artery dissection | 위 |
| Rib fracture (osteoporosis) | 드묾, 노인 주의 |
| Disc herniation 악화 | 드묾, SLR 재평가 중요 |

### 5.4 부작용 발생 시 응급 대응

```
증상 발생 → 즉시 교정 중단 → 상세 기록
→ 신경학적 평가 재실시
→ Red Flag 해당 시 응급실
→ 경증 (soreness) → 환자 교육 · 아이싱
→ 24-48h 호전 없으면 재평가
```

### 5.5 의료 분쟁 방지

- **Informed Consent** 문서 — 환자 서명
- Pre-treatment 상태 상세 기록
- 부작용 가능성 사전 설명 (VAD, rare 포함)
- 교정 전후 증상·징후 변화 기록

## 제6부. 절대·상대 금기 통합 체크리스트 {#part6}

### 6.1 🔴 절대 금기 (Absolute — 교정 절대 금지)

1. **척수 압박** — myelopathy · spinal cord 압박 징후
2. **Cauda equina syndrome** — saddle anesthesia · 배뇨배변 장애
3. **병적 골절** — 종양·감염 전이·compression fx (acute)
4. **척추 종양** — 원발성 또는 전이성
5. **활동성 감염** — discitis · osteomyelitis · 결핵성 척추염
6. **동맥 박리** — VAD · carotid dissection 활동성
7. **출혈성 질환** (INR &gt;3.0, 혈소판 &lt;50,000)
8. **Rheumatoid arthritis — atlantoaxial instability**
9. **Severe osteoporosis** (T-score &lt; -3.5) + 최근 골절
10. **최근 척추 수술** (&lt; 3개월)
11. **환자 거부** · 교정에 대한 심한 공포

### 6.2 🟡 상대 금기 (Relative — 주의 · low force · 조건부)

1. **경도-중등도 osteoporosis** (T-score -2.5 to -3.5)
2. **임신 후기** (28주+) — 특히 복와위 피함
3. **만성 스테로이드 사용** (3개월+)
4. **Anticoagulant 복용** (INR 조절 상태)
5. **당뇨 합병증** (neuropathy severe)
6. **Severe atherosclerosis** (노인)
7. **Fibromyalgia** (widespread pain) — gentle mobilization만
8. **Hypermobility syndrome** (EDS 등)
9. **심혈관 불안정** (최근 MI, 심부전 NYHA III-IV)

### 6.3 적응증 재확인 (Screening 최종)

교정 직전 체크리스트:
```
□ Red Flag 재확인 (2주 이내 새 증상 질문)
□ VBI 질문 (경추 교정 시)
□ VAS 기록
□ ROM 측정
□ 환자 동의 재확인
□ 금기 점검 완료
```

## 제7부. Post-adjustment Soreness 대응 {#part7}

### 7.1 정상 vs 이상 구분

**정상 (80%+)**:
- 치료 후 24-72시간 소재 통증 (mild)
- 기존 통증 부위 근처 rather than 새 부위
- 휴식 · 아이싱으로 호전

**이상 (즉시 재평가)**:
- 새로운 방사통 · 신경학적 결손
- 발열 · 심한 피로
- 72시간 초과 지속 악화
- 호흡·흉통·심한 두통

### 7.2 대응 프로토콜

#### 정상 soreness
- 환자 안심시키기 (치료 반응, 생리적)
- **Ice** 15-20분 × 3-4회/일 × 1-2일
- NSAID 단기 (환자 원할 시, 의사 처방)
- 24-48h 후 재평가

#### 이상 발생
- 즉시 응급실 or 의사 의뢰
- 영상 (MRI · X-ray) 필요
- 환자 상태 상세 기록

### 7.3 반복적 soreness 발생 환자

- Force 재조절 (감량)
- Pre-treatment ice · 열 치료 고려
- 다른 기법 (Activator, Drop table) 시도
- 증상 호전 없으면 전체 치료 계획 재검토

## 제8부. 통합 치료 전략 — 다학제 협진 {#part8}

### 8.1 Diversified + 운동치료

- **Core stability** (복직근·복횡근·diaphragm)
- **McKenzie extension** (요추 디스크)
- **Neural mobilization** (방사통)
- **Motor control training**

### 8.2 약물·주사 협진

- NSAID 단기 사용 (AMA 원칙: short-term)
- Steroid injection (radicular pain) — 의사 영역
- Opioid 피하기 (중증 외)

### 8.3 Psychology · Lifestyle

- 만성 통증 → 인지행동치료 (CBT)
- 수면 위생 · 체중 관리
- 금연 권고 (디스크 영양 향상)

### 8.4 외과 의뢰 기준

**요추 수술 고려**:
- 6-12주 보존 치료 불응 + MRI 상 큰 디스크 탈출
- 진행성 운동 결손
- Cauda equina · 새로운 sphincter 기능 상실

**경추 수술 고려**:
- 진행성 myelopathy
- 심한 신경근 증상 + MRI 상 큰 디스크 탈출
- Instability (fracture · 외상)

## 제9부. 한국 임상 현장 — 도수치료·정형·재활의학 협진 {#part9}

### 9.1 한국 의료 생태계 속 Diversified

- **도수치료 (MD/PT)** — 한국 건강보험 비급여
- 카이로프랙틱은 **법적 면허 없음** (2026 현재)
- **정형외과·재활의학과 의사가 Diversified 기법 활용** — 일부 의사 훈련 받음
- **도수치료 훈련 PT**가 실무 주체 — 국가공인·학회 교육

### 9.2 의료진 간 역할 분담

| 역할 | 담당 |
|------|------|
| 진단·영상 판독 | 정형·재활의학 **의사** |
| 처방·약물 | **의사** |
| Diversified 수기 | **의사** 또는 훈련 PT |
| 운동 치료 · 재활 | **PT** · 작업치료사 |
| 환자 교육 · 생활 지도 | 팀 전체 |

### 9.3 협진 모델 예시

#### 급성 요통 환자 워크플로우
```
내원 → 정형외과 진료 (의사)
 ├─ Red Flag 스크리닝 + X-ray 필요 시
 ├─ 진단명 결정 · 금기 확인
 └─ PT 의뢰 (Diversified + 운동)
     ├─ 1주차: Diversified 2-3회
     ├─ 2주차: Diversified 1회 + 운동 시작
     └─ 3-6주: 운동 중심 + 간헐적 Diversified
→ 호전 없음 → MRI → 재평가 → 필요 시 주사·수술
```

### 9.4 한국 의료법 유의사항

- Diversified 시술은 "도수치료" 또는 "운동치료" 코드로 청구
- 카이로프랙틱 특화 용어 사용 시 면허 오해 위험 → **"척추 도수치료"** 표준 용어 권장
- 환자 동의서 · 진료 기록 철저

### 9.5 학회·연수

- 대한도수의학회 · 대한재활의학회 연수 프로그램
- 대한정형외과학회 SMT 심포지엄
- 해외 연수 (Palmer College · Life Chiropractic 등)

## 🏁 마무리

본 4주 Diversified 강의록은 **근거 기반 의학**의 프레임 안에서 Diversified HVLA를 체계적으로 다루었습니다. 핵심 원칙 3가지:

1. **Evidence First** — 근거 수준 명시 · 🔴 No evidence 주장 배제
2. **Safety First** — Red Flag · 금기 · 부작용 관리 우선
3. **Patient First** — 환자 기반 결정 · 다학제 협진 · 지속 가능 관리

임상 의사결정의 **확신**이 아닌, 환자에게 안전하고 효과적인 기술을 **정직하게 전달**하는 것이 이 강의의 목표입니다.
