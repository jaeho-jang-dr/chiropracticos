# Lloyd Galaxy 900HS 및 톰슨 테크닉(Thompson Technique) 학습 가이드

이 학습 가이드는 Lloyd Galaxy 900HS 테이블의 운영 매뉴얼과 톰슨 테크닉의 원리를 체계적으로 정리하여 제공합니다. 이 문서는 장비의 안전한 조작, 유지관리 절차, 그리고 핵심적인 카이로프랙틱 조절 기법에 대한 심도 있는 이해를 돕기 위해 작성되었습니다.

---

## 1. 핵심 개념 요약

### 안전 및 운영 원칙
*   **환자 안전:** 환자를 테이블 위에 혼자 두어서는 안 되며, 환자는 팔을 암레스트에 올리고 테이블 중앙에 위치해야 합니다.
*   **조작자 주의:** 테이블을 조작하기 전 모든 주의 및 경고 라벨을 숙지해야 하며, 컨트롤 조작자는 한 명으로 제한합니다.
*   **드롭(Drop) 확인:** 환자를 조정하기 전 반드시 모든 드롭 장치의 장력(Tension)을 점검하고 테스트해야 합니다.

### 유지관리 일정
테이블의 수명 연장과 최상의 상태 유지를 위해 다음 일정을 준수해야 합니다.

| 항목 | 주기 | 작업 내용 |
| :--- | :--- | :--- |
| **쿠션 청소** | 매일 | 따뜻한 비눗물로 체유(Body oils) 제거 후 헹굼 및 건조 |
| **크롬 부품** | 매주 | 외관 유지를 위한 세척 |
| **윤활 작업** | 6개월 | 모든 피벗 포인트 및 금속 슬라이딩 메커니즘 윤활 (프릭션 록 제외) |
| **유압유 점검** | 매년 | Lubriplate HO1 유압유 점검 및 누유 확인 |
| **기타 점검** | 수시/정기 | 볼트 및 너트의 풀림 상태 확인 |

### 톰슨 테크닉 (Thompson Technique)
*   **역사:** 1952년 J. 클레이 톰슨(Dr. J. Clay Thompson) 박사가 최초의 "드롭" 헤드피스를 개발하며 도입되었습니다.
*   **핵심 원리:** 뉴턴의 제1운동법칙을 기반으로 하며, 공기압으로 구동되는 테이블의 드롭 메커니즘을 통해 최소한의 힘으로 고속 조절(High speed thrust)을 수행합니다.
*   **분석 방법:** 환자가 엎드린 상태(Prone)에서 다리 길이의 차이를 감지하여 신경계 불균형을 확인하고, 머리를 좌우로 돌리게 하여 교정 순서를 결정합니다.

## 2. 단답형 연습 문제

**Q1. Lloyd Galaxy 900HS 테이블의 틸트 세이프가드(Tilt Safeguard) 스위치를 활성화한 후, 테이블을 내릴 수 있는 제한 시간은 몇 초입니까?**
(정답: 약 30초)

**Q2. 자동 콕킹 드롭(Automatic Cocking Drops) 선택 노브에서 'L'이 의미하는 부위는 어디입니까?**
(정답: 요추(Lumbar))

**Q3. 톰슨 테크닉에서 다리 길이의 불일치를 판단하기 위해 환자가 취하는 기본 자세는 무엇입니까?**
(정답: 프론 자세(Prone, 엎드린 자세))

**Q4. 헤드 쿠션의 장력을 조절할 때, 장력을 증가시키려면 노브를 어느 방향으로 돌려야 합니까?**
(정답: 시계 방향)

**Q5. 스프링 브레이크어웨이(Spring Breakaway) 체스트 쿠션을 잠그거나 해제할 때 사용하는 노브의 위치는 조작자가 테이블의 어느 쪽을 향할 때 기준입니까?**
(정답: 테이블의 오른쪽)

**Q6. 하이로(Hylo) 위치에서 테이블 높이를 조절하기 위해 헤드/체스트/골반 확장 및 수축 스위치를 사용할 때, 쿠션을 확장하려면 스위치를 어느 방향으로 토글해야 합니까?**
(정답: 테이블의 머리 쪽(Head end))

## 3. 심층 탐구를 위한 에세이 질문

**주제 1: 드롭 테이블 메커니즘의 기계적 이점과 임상적 효율성**
뉴턴의 제1운동법칙이 톰슨 테크닉의 드롭 테이블에 어떻게 적용되는지 설명하고, 이 메커니즘이 환자와 의사 모두에게 제공하는 물리적 이점(힘의 최소화, 교정의 정확성 등)에 대해 서술하시오.

**주제 2: 의료 장비 유지관리와 환자 안전의 상관관계**
매뉴얼에 명시된 일일, 주간, 반기별 유지관리 절차가 단순히 장비의 수명을 늘리는 것을 넘어, 실제 치료 과정에서 환자의 안전을 어떻게 보장하는지 Lloyd Galaxy 900HS의 구체적인 기능을 예로 들어 논하시오.

**주제 3: 톰슨 테크닉의 신경학적 분석 과정**
다리 길이 차이 분석과 머리 회전 테스트가 척추 아탈구(Vertebral Subluxation)를 식별하는 데 있어 어떤 역할을 하는지, 그리고 이러한 분석이 왜 교정의 순서를 결정하는 데 중요한지 설명하시오.

## 4. 주요 용어 사전 (Glossary)

| 용어 | 정의 |
| :--- | :--- |
| **척추 아탈구 (Vertebral Subluxation)** | 신경계에 간섭이나 자극을 일으켜 신체의 자가 치유 능력을 방해하는 상태. |
| **하이로 (Hylo)** | 테이블이 수평 상태에서 수직(기립) 상태로, 또는 그 반대로 움직이는 기능. |
| **드롭 (Drop)** | 조절 시 관절의 정상 가동 범위를 따라 해당 섹션이 약간 아래로 떨어지며 교정을 돕는 기능. |
| **스프링 브레이크어웨이 (Spring Breakaway)** | 복부가 큰 환자 등을 수용하기 위해 체스트 쿠션이 압력에 따라 부드럽게 내려갔다 복원되는 부유(Floating) 효과. |
| **콕킹 (Cocking)** | 드롭 기능을 활성화하기 위해 해당 쿠션을 들어 올려 고정하는 준비 동작. |
| **뉴턴의 제1운동법칙 (Newton's First Law)** | 톰슨 테이블의 기계적 이점을 설명하는 물리 법칙으로, 낮은 힘으로 높은 속도의 조절을 가능케 함. |
| **틸트 세이프가드 (Tilt Safeguard)** | 승인되지 않은 조작자가 수직 위치의 테이블을 내리는 것을 방지하는 안전 스위치 시스템. |
| **발판 (Foot Stand)** | 하이로 작동 시 환자가 서 있을 수 있도록 지원하는 테이블 하단의 플레이트. |
