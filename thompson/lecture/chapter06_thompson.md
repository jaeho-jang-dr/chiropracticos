## 서론 — Thompson의 위상 {#서론}

**Thompson Terminal Point Technique**는 Palmer Package 4대 기법 중 **기계 공학을 도입한 첫 세대** 기법. Newton 운동 법칙에 기반한 드롭 테이블로 추력을 증폭하며, 술자와 환자 모두의 부담을 최소화.

- 미국 <abbr class="med-abbr" title="Doctor of Chiropractic · 카이로프랙틱 의사 학위">DC</abbr>의 ~55.9% 사용 (ACA)
- 고령·임산부·골다공증·수기 교정 공포 환자에 특히 적합

## 드롭 테이블 — 기계 공학의 도입 {#드롭-테이블}

### 구조

테이블이 **segmental drop pieces** (분절 단위 하강 구역)로 분할:
- **Cervical piece** (경추)
- **Thoracic piece** (흉추)
- **Lumbar piece** (요추)
- **Pelvic piece** (골반)

### 작동 원리 (Newton 3법칙)

1. 각 piece는 **약간 들린 상태** (1-3 cm)에서 공압 잠금
2. 술자가 contact + 추력을 가하면 piece가 **순간 하강** (0.1초 이내)
3. 추력 + 낙하가중 = **효과적 감속** → 분절에 전달되는 impulse 증폭
4. 술자는 **가벼운 힘**으로도 HVLA 달성

### 공압 텐션 조절

환자 체중·근긴장·부위별로 **piece drop tension** 조절:
- 경추: 낮은 텐션 (~5-10 lb)
- 요추·골반: 중-높은 텐션 (~30-50 lb)
- 술자가 사전에 miniature lever로 조정

### 관성에 의한 교정 힘 — 벡터와 생리 효과 {#관성}

Thompson 드롭 교정의 물리학은 **Newton 제1법칙(관성의 법칙)**과 **운동 에너지(Kinetic Energy)**를 기반으로 한다.

#### 힘의 형태 — 고속 저진폭(HVLA)

신체가 드롭 테이블과 함께 하강하다가 매우 짧은 거리(1.5-3 cm)에서 갑자기 정지할 때, 관성의 법칙에 의해 **뼈와 관절의 운동량(Momentum)**은 수십 ms 동안 계속 진행하려 한다. 이 순간 근육이 반사적으로 수축하며 방어하기 전에 **운동 에너지가 관절에 직접 침투**하여 분절이 제자리로 이동한다. 결과적으로 표준 수기 추력보다 최대 30% 적은 압축력으로 동등한 관절 운동을 기대할 수 있다.

#### 힘의 벡터 — 비틀기 없는 직선적 전달

비틀기(Twisting)·굴곡·회전 벡터를 배제하고, **해부학적 관절면에 평행한 직선(Linear) 벡터**만 적용한다. 변위 유형에 따라 교정 벡터가 달라진다.

| 변위 유형 | 교정 벡터 |
|-----------|-----------|
| PI 장골 (후하방) | IS (하→상) + PA (후→전) |
| EX 장골 (외회전) | LM (외→내) + PA + IS (3차원 조합) |
| IN 장골 (내회전) | ML (내→외) + SI (상→하) + arcing tissue pull |
| 천골 후방 회전 (P-L/P-R) | ML (내→외) + PA (후→전) |
| 천골 전방 회전 (A-L/A-R) | LM (외→내), 서혜부 접촉 |

벡터가 관절면을 정확히 통과하므로 주변 연부 조직의 에너지 흡수가 최소화되고, 타겟 분절에 운동량이 집중된다.

#### 인체에 미치는 생리·신경학적 효과

| 효과 | 기전 |
|------|------|
| 관절 에너지 집중 | 주변 조직으로 분산되지 않고 타겟 관절에 운동량 전달 |
| 기계수용기 자극 | Pacinian·Ruffini corpuscle + 근방추의 빠른 활성화 |
| 패턴 차단(Pattern Interrupt) | 신경계의 만성 과긴장 패턴 일시적 재설정 |
| 통증 억제 | 척수 후각 gate control, DNIC 활성화 |
| 환자 협조 향상 | 뒤틀림·꺾임 없어 방어 반사(Guarding) 감소 → 근육 이완 상태에서 교정 |

## Derifield-Thompson Leg Check {#derifield}

Thompson 분석의 핵심 도구. **하지장(apparent leg length) 비교**를 통해 기능장애 분절을 경추·골반·천골 수준으로 구분한다. Romer & Mabel Derifield 부부(1940-50년대)의 원형을 Thompson이 체계화하였다.

### 4.1 기본 검사 절차

**환자 자세**: 복와위(prone), 양측 내측 복숭아뼈(medial malleolus)를 기준으로 발뒤꿈치를 나란히 맞춤.

**3단계 검사 순서**:

1. **신전 단계** — 무릎 펴고(knee extension) 하지장 비교 → 짧은 다리(short leg) 측 확인
2. **굴곡 단계** — 양 무릎을 90도로 굴곡 후 하지장 비교 → +D/-D 감별
3. **경추 테스트** — 머리를 좌·우로 회전시키며 하지장 변화 관찰 → 경추 증후군 여부

세 단계의 결과 조합으로 세 가지 증후군을 감별한다.

---

### 4.2 경추 증후군 (Cervical Syndrome)

**소견**: 복와위 신전 상태에서 **고개를 좌우로 돌렸을 때**, 불균형했던 하지장이 동등해지거나 반대로 동등했던 하지장에 차이가 생기는 반응.

**해석 원리**: 경추 회전 동작이 하지장 균형에 영향을 미쳤다면, 신경 간섭(Neurological Interference)의 근원이 골반이나 요추가 아닌 **상부 경추**에 존재함을 시사한다. 목의 고유수용성 수용기(proprioceptors)가 자세 조절 및 하지 근긴장과 신경학적으로 연결되어 있기 때문이다.

> **임상 적용**: 경추 증후군이 확인되면 골반 교정에 앞서 **상부 경추(C1-C2)를 우선 교정**한다. 교정 후 leg check를 재확인하여 반응을 평가한다.

---

### 4.3 양성 데리필드 (+D, Positive Derifield) — PI 장골 변위

**소견**: 신전 상태에서 짧았던 다리가 **무릎을 90도 굴곡하면 길어지거나 같아지는** 반응 (crosses over).

**변위 위치**: 짧은 다리 쪽 장골의 **후하방(PI, Posterior-Inferior) 변위**를 나타내는 경향이 있다.

#### 근육 생체역학 기전 — 편심성 수축(Eccentric Contraction)

| 단계 | 기전 |
|------|------|
| ① 장골 PI 변위 | 장요근(iliopsoas)·대퇴직근(rectus femoris)·봉공근(sartorius) 등 고관절 굴곡근 약화 |
| ② 보상 반응 | 해당 측 고관절 굴곡근의 긴장도(tone)가 증가 → **편심성 수축** 상태로 전환 |
| ③ 굴곡 시 반응 | 무릎을 90도 굴곡하면 이미 긴장된 굴곡근(대퇴직근·봉공근)이 더욱 당겨져 뻣뻣해짐 |
| ④ 하지장 변화 | 골반부에서 발을 상대적으로 더 높이 끌어올려 짧았던 다리가 **길어 보임** |

**편심성 수축의 핵심**: 근육이 늘어나는 방향으로 긴장(저항)을 유지하는 상태. 고관절 굴곡근이 신전 위치에서 이미 최대로 늘어나 있으므로, 굴곡 시 당기는 힘이 극대화된다.

> **교정 목표**: PI 장골 교정 → PSIS 하외측 접촉 → IS(하→상)·PA(후→전) 벡터 추력.

---

### 4.4 음성 데리필드 (-D, Negative Derifield) — 회전 변위

**소견**: 신전 상태에서 짧았던 다리가 **무릎 굴곡 후에도 여전히 짧거나 더 짧아지는** 반응.

**변위 의미**: 장골 또는 천골이 **세로축(θY축)을 중심으로 회전**하는 분절 기능장애(Segmental dysfunction)를 시사한다.

가능한 변위 유형:
- 장골의 전상방(AS, Anterior-Superior) 변위
- 장골의 외회전(EX) 또는 내회전(IN)
- 천골의 후방 회전(P-L/P-R) 또는 전방 회전(A-L/A-R)

#### 근육 생체역학 기전 — 동심성 수축(Concentric Contraction)

| 단계 | 기전 |
|------|------|
| ① 장골 AS/회전 변위 | 대퇴 신전근의 강한 수축으로 장골이 전상방·측방으로 당겨짐 |
| ② 근육 상태 | 짧은 다리 측 고관절 굴곡근이 **이미 짧아진 방향으로 수축** → 동심성 수축 |
| ③ 굴곡 시 반응 | 무릎 굴곡 시 긴장도(stiffness)가 그대로 유지되어 골반을 추가로 끌어올리지 않음 |
| ④ 하지장 불변 | 긴 다리는 계속 길고, 짧은 다리는 계속 짧게 유지 (또는 더 짧아짐) |

**+D vs -D 비교**:

| 구분 | 양성 +D | 음성 -D |
|------|---------|---------|
| 변위 방향 | PI (후하방) | AS / IN / EX / 천골 회전 |
| 근육 상태 | 편심성 수축 (늘어나며 저항) | 동심성 수축 (짧아지며 당김) |
| 굴곡 반응 | 짧은 다리가 **길어짐** | 변화 없거나 **더 짧아짐** |
| 교정 방향 | IS + PA | 변위별 상이 (아래 참조) |

---

#### 4.4.1 분리 검사 (Isolation Test / θY축 분절 기능장애 검사)

음성(-D)이 확인되면 **정확한 회전 변위 방향**을 두 그룹으로 좁히기 위해 시행한다.

**수행 절차 (6단계)**:

1. **위치**: 술자는 검사하려는 다리의 허벅지 높이 부근에 서서 대각선 아래쪽을 바라본다.
2. **무릎 고정**: 환자에게 검사할 측 무릎을 곧게 펴서 고정(lock)하도록 지시한다.
3. **고관절 신전**: 환자가 고관절을 신전시켜 다리를 들어 올리고, 저항이 느껴지는 끝 범위(end range)까지 진행한다.
4. **SIJ 개입(Engage)**: 술자가 수동으로 고관절을 약간 더 신전시켜 **천장관절(SIJ)에 기계적 부하**가 걸리도록 한다.
5. **다리 내려 확인**: 복와위 신전 상태로 돌아와 짧은 다리가 여전히 짧은지 확인한다.
6. **굴곡 반응 관찰**: 양 무릎을 90도로 굴곡 후 반응 측 하지장 변화를 관찰한다.

**생체역학 원리**: 고관절을 끝 범위까지 신전시키면 θY축으로 이미 회전된 장골·천골에 인위적인 부하가 추가된다. 이 부하가 특정 회전 방향의 가동 한계를 자극하여, 이어지는 무릎 굴곡 시 골반에 미치는 보상적 당김 방향을 결정한다.

**분리 검사 결과 해석**:

| 굴곡 시 반응 | 의미하는 변위 그룹 |
|-------------|-----------------|
| 짧은 다리가 **길어짐** | EX 장골(외회전) 또는 천골 후방 회전(P-L/P-R) |
| 짧은 다리가 **더 짧아짐** | IN 장골(내회전) 또는 천골 전방 회전(A-L/A-R) |

---

#### 4.4.2 관절 압박 검사 (Articular Pressure Test) — 변위 확진

분리 검사로 두 가능성을 좁힌 뒤, 관절 압박 검사로 정확한 변위를 확진한다. **압박 후 하지장이 동등해지면** 해당 변위로 확진한다.

---

**그룹 A — 분리 검사에서 짧은 다리가 길어진 경우**
*후보 변위: EX 장골 vs 천골 후방 회전(P-L/P-R)*

**① 천골 후방 회전 압박 검사 (먼저 시행)**
- **위치**: 검사 반대편에 선다.
- **접촉**: 제1-2 천추 결절 외측의 **천골 익(Sacral ala)**에 손바닥 척골 측(hypothenar)을 접촉.
- **방향**: **내측→외측(M→L) + 후방→전방(P→A)**으로 강한 압박.
- **확진**: 신전·굴곡 모두에서 하지장이 동등해지면 → 천골 후방 회전 확진.

**② EX 장골 압박 검사** (천골 압박으로 해결되지 않을 때)
- **위치**: 검사 측에 선다.
- **접촉**: **후상장골극(PSIS)** 하외측에 손목(pisiform)을 접촉.
- **방향**: **외측→내측(L→M) + 하방→상방(I→S)** — SIJ 관절면을 따라 압박.
- **확진**: 하지장이 동등해지면 → EX 장골 확진.

---

**그룹 B — 분리 검사에서 짧은 다리가 더 짧아진 경우**
*후보 변위: IN 장골 vs 천골 전방 회전(A-L/A-R)*

**③ IN 장골 압박 검사 (먼저 시행)**
- **위치**: 검사 반대편에 선다.
- **접촉**: **PSIS 내측**에 접촉.
- **방향**: **상방→하방(S→I) + 내측→외측(M→L)** — 호를 그리며(arcing tissue pull) 압박.
- **확진**: 신전·굴곡 모두에서 하지장이 동등해지면 → IN 장골 확진.

**④ 천골 전방 회전 압박 검사** (IN 장골 압박으로 해결되지 않을 때)
- **위치**: 검사 반대편에 선다.
- **접촉**: **서혜인대(inguinal ligament)** 중간 외측 — ASIS 아래 약 2인치 지점.
- **방향**: **외측→내측(L→M)**으로 압박.
- **확진**: 하지장이 동등해지면 → 천골 전방 회전 확진.

---

#### 4.4.3 전체 감별 진단 알고리즘

```
복와위 신전 → 하지장 비교
    │
    ├─ 머리 회전 시 하지장 변화?
    │      YES → [경추 증후군] → 상부 경추(C1-C2) 교정 우선
    │
    └─ 머리 회전에 반응 없음 → 무릎 90도 굴곡 후:
            │
            ├─ 짧은 다리가 길어짐 / 같아짐
            │      → [+D 양성 데리필드]
            │      → PI 장골 교정 (IS + PA 벡터)
            │
            └─ 변화 없거나 더 짧아짐
                   → [-D 음성 데리필드]
                   → 분리 검사(Isolation Test) 시행
                          │
                          ├─ 굴곡 시 길어짐:
                          │    ① 천골 익 ML+PA 압박 → 동등? → 천골 후방 회전 (P-L/P-R) 교정
                          │    ② PSIS 하외측 LM+IS 압박 → 동등? → EX 장골 교정
                          │
                          └─ 굴곡 시 더 짧아짐:
                               ③ PSIS 내측 SI+ML 압박 → 동등? → IN 장골 교정
                               ④ 서혜부 LM 압박 → 동등? → 천골 전방 회전 (A-L/A-R) 교정
```

---

### 4.5 신뢰도와 임상 한계 {#신뢰도}

- **측정자 간 신뢰도**: 연구마다 변동 (ICC 0.3-0.7) — Cooperstein 2013 review
- **숙련도 요건**: 6시간+ 실습 필요 (Life University 보고)
- **단독 사용 금지**: Motion Palpation·정형 검사(SLR, Patrick's FABER, FABQ)와 반드시 병행
- **진단적 타당도**: leg check 소견 자체보다 **교정 후 기능 개선**을 outcome으로 삼는 것이 임상적으로 현실적
- 본 강의 입장: 🟡 **보조 분석 도구**로만 수용. 진단 결정의 단독 근거 불가.

## 교정 프로토콜 {#교정}

### 요추·골반 (가장 흔한 적용)

1. 환자 복와위 on Thompson table
2. Leg check → 분절 target 결정
3. Pelvic piece 텐션 조정
4. 술자 pisiform/hypothenar 접촉
5. HVLA thrust → piece drop → 감속 → 교정 완료
6. Leg check 재확인 (효과 확인)

### 경추

- Cervical piece 매우 낮은 텐션
- 환자 복와위 또는 측와위
- 경추 drop piece는 머리 끝 작은 영역만 하강

### 흉추

- 앙와위 AP thrust (Diversified와 유사)
- 테이블 drop은 보조

### 사지

- Thompson은 주로 척추·골반 · 사지는 Diversified와 혼용

## Aff/Def/Eff 해석 {#aff-def-eff}

Chapter 2 프레임으로 Thompson 재해석:

### Afferentation

- HVLA + **drop으로 인한 추가 Pacinian (II type, vibration) 자극**
- 순간 감속이 빠른 기계수용기에 강한 신호

### Deafferentation 해소

- 분절 hypomobility → Motion Palpation / leg check로 검출 → 교정으로 mechanoreceptor 재활성

### Efferentation

- 일반 HVLA와 유사 — α/γ-motor neuron 재설정, 척수 후각 gate control

### 특이점

- **술자 근력 부담 감소** → 경력 DC 장기 커리어 보호
- **환자 심리 부담 감소** → 고령·공포 환자 수용도

## 🟡 비판적 시각 {#비판}

### 1. Leg Check 재현성

- Inter-examiner reliability 🟠 limited
- **훈련·표준화 부족 시 오해석 가능**
- 권장: Motion Palpation·정형 검사와 병행

### 2. 테이블 의존성

- Thompson 장비(Zenith·Lloyd·Williams 브랜드) 고가 (10,000+ USD)
- **장비 정기 점검 필수** — 공압 시스템 고장 시 환자 위험
- 드롭 piece 텐션이 부적절하면 효과 없거나 과도한 impact

### 3. 확장 주장 없음 (다행)

Thompson은 Gonstead·<abbr class="med-abbr" title="Hole-In-One · B.J. Palmer 상부경추 단일 교정 이론 (Toggle Recoil)">HIO</abbr>와 달리 **"전신 질환 치료" 같은 확장 주장을 별로 하지 않음**. 기계적 SMT 도구로서의 정체성이 비교적 명확.

### 4. 단점

- 장비 공간 필요
- 이동형 진료 불가
- Cervical 교정 신뢰도는 제한적
